# 1-1. 스토어 설명

Chrome Web Store, Firefox Add-ons, Whale Store에 사용하는 스토어 설명 원본이다.
핵심 가치와 검색어(경희대학교, 인포21, e-campus 등)를 첫 문단에 둔다.
버전별 변경 목록은 두지 않는다. 변경 이력은 [홈페이지의 업데이트 섹션](https://kangkyunghyun.github.io/LinKHU/#releases)이 맡는다.

```text
§1-1-1   한국어                                          스토어에 제출하는 설명 원문
§1-1-2   갱신 절차                                       기능 목록 갱신과 제출
```

## 1-1-1 한국어

```text
클릭 한 번으로 인포21, e-campus, 중앙도서관 등 경희대학교 교내 서비스로 바로 이동하세요.
LinKHU는 경희대학교 구성원을 위한 바로가기 확장 프로그램입니다.

[주요 기능]
- 경희대학교 자주 찾는 사이트 바로가기 제공
- 학점교류로 경희사이버대 강의를 듣는다면 포털과 LMS도 담아 쓸 수 있습니다.
- 커스텀 기능: 원하는 사이트만 담고, 드래그 앤 드롭으로 순서를 변경할 수 있습니다.

[편의 기능]
- 설정 페이지 목록에서 서비스를 새 탭으로 열어 어떤 사이트인지 먼저 확인할 수 있습니다.
- 설정 페이지의 카테고리 필터로 원하는 분류만 골라 보면서 목록을 구성할 수 있습니다.
- 시스템/라이트/다크 테마를 선택할 수 있습니다. (시스템 모드는 운영체제 설정을 따릅니다)
- 단축키[Ctrl(Cmd) + Shift + L]로 확장 프로그램을 실행할 수 있습니다. 이 단축키는 브라우저의 단축키 설정에서 바꿀 수 있습니다.
- 서비스 검색: [/] 키로 검색창에 바로 이동하고, Enter로 첫 번째 결과를 열 수 있습니다.
- 확장 프로그램이 실행된 상태에서 숫자키[1~9]를 통한 빠른이동이 가능합니다.

[지원 사이트]
교내 서비스, 단과대, 대학원, 학과 사이트 257개를 지원합니다. 설정 창에서 커스텀할 수 있습니다.
자세한 리스트는 다음 링크를 참고해주세요.
https://github.com/kangkyunghyun/LinKHU/blob/main/docs/supported-services.md

[문의 및 기여]
사이트 추가나 개선 의견은 확장 프로그램이나 홈페이지의 [문의하기]에서 유형을 골라 보낼 수 있습니다.
Github Issue와 Pull Request를 통한 기여도 환영합니다.
홈페이지: https://kangkyunghyun.github.io/LinKHU/

도움이 되었다면 스토어 리뷰와 Github Stars 부탁드립니다. Stars는 개발자를 춤추게 합니다.
https://github.com/kangkyunghyun/LinKHU
```

## 1-1-2 갱신 절차

1. 새 릴리스 노트(`docs/releases/vX.Y.Z.md`)에서 계속 알릴 기능이 있으면 `[주요 기능]`이나 `[편의 기능]`에 한 줄로 넣는다.
   `[지원 사이트]`의 서비스 개수도 함께 본다. 첫 문단의 핵심 가치 소개는 릴리스와 무관하게 유지한다.
2. 1에서 바뀐 것이 있을 때만 Chrome / Firefox / Whale 대시보드의 설명에 붙여넣는다. 바뀐 것이 없으면 설명은 그대로 둔다.
3. 버전별 변경은 설명에 쓰지 않는다. Firefox 버전 노트는 제출 워크플로가 릴리스 노트로 채우고, Whale 버전 설명은 제출할 때 릴리스 노트의 사용자에게 보이는 절을 넣는다.
