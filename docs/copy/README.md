# 배포 문구

스토어에 제출하거나 커뮤니티에 게시하는 문구 원본을 기록한다.

문구 작성 기준과 검증 명령은 [release-copy 스킬](../../.claude/skills/release-copy/SKILL.md)이 원본이며 여기서 반복하지 않는다.

## 읽는 순서

1은 배포 문구 계층이다.

```text
1-1   STORE-LISTING    스토어 설명
1-2   COMMUNITY-POST   커뮤니티 홍보글
```

## 문서와 책임

| 문서 | 책임 |
| --- | --- |
| [1-1-STORE-LISTING.md](1-1-STORE-LISTING.md) | 스토어 설명 |
| [1-2-COMMUNITY-POST.md](1-2-COMMUNITY-POST.md) | 커뮤니티 홍보글 |

## 변경 원칙

1. 릴리스마다 스토어 설명의 업데이트 섹션을 교체한다.
2. 커뮤니티 홍보글에는 버전별 변경 목록을 두지 않는다. 계속 알릴 기능만 본문 문단에 녹인다.
3. 작성 기준과 검증은 [release-copy 스킬](../../.claude/skills/release-copy/SKILL.md)을 따른다.
