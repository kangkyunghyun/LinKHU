# Store Listing

Chrome Web Store, Firefox Add-ons, Whale Store에 사용하는 스토어 설명 원본입니다.
핵심 가치와 검색어(경희대학교, 인포21, e-campus 등)를 첫 문단에 두고,
`[vX.Y.Z 업데이트]` 섹션은 맨 아래에서 릴리스마다 교체합니다.

## 한국어

```text
클릭 한 번으로 인포21, e-campus, 중앙도서관 등 경희대학교 교내 서비스로 바로 이동하세요.
LinKHU는 경희대학교 구성원을 위한 바로가기 확장 프로그램입니다.

[주요 기능]
- 경희대학교 자주 찾는 사이트 바로가기 제공
- 커스텀 기능: 원하는 사이트만 담고, 드래그 앤 드롭으로 순서를 변경할 수 있습니다.

[편의 기능]
- 설정 페이지 목록에서 서비스를 새 탭으로 열어 어떤 사이트인지 먼저 확인할 수 있습니다.
- 설정 페이지의 카테고리 필터로 원하는 분류만 골라 보면서 목록을 구성할 수 있습니다.
- 시스템/라이트/다크 테마를 선택할 수 있습니다. (시스템 모드는 운영체제 설정을 따릅니다)
- 단축키[Ctrl(Cmd) + Shift + L]로 확장 프로그램을 실행할 수 있습니다.
- 서비스 검색: [/] 키로 검색창에 바로 이동하고, Enter로 첫 번째 결과를 열 수 있습니다.
- 확장 프로그램이 실행된 상태에서 숫자키[1~9]를 통한 빠른이동이 가능합니다.

[지원 사이트]
교내 서비스, 단과대, 학과 사이트 165개를 지원합니다. 설정 창에서 커스텀할 수 있습니다.
자세한 리스트는 다음 링크를 참고해주세요.
https://github.com/kangkyunghyun/LinKHU/blob/main/docs/supported-services.md

[문의 및 기여]
사이트 추가나 개선 의견은 확장 프로그램의 [문의하기]에서 바로 보낼 수 있습니다.
Github Issue와 Pull Request를 통한 기여도 환영합니다.
홈페이지: https://kangkyunghyun.github.io/LinKHU/

도움이 되었다면 스토어 리뷰와 Github Stars 부탁드립니다. Stars는 개발자를 춤추게 합니다.
https://github.com/kangkyunghyun/LinKHU

[v2.7.1 업데이트]
- 팝업에서 이름이 긴 서비스의 뒷글자가 잘려 보이던 것을 고쳤습니다. '국제통상금융투자학부'처럼 두 줄로 넘어가는 이름이 이제 끝까지 보입니다.
- 카드 이름 글씨를 조금 키워 읽기 편해졌습니다.
- 설정 페이지에서 항목을 드래그할 때 강조되는 영역의 여백이 아래쪽만 떠 보이던 것을 고쳤습니다.
- 새 버전이 나왔을 때 팝업 상단 안내가 두 줄로 밀리던 것을 고쳤습니다.
```

## 갱신 절차

1. 새 릴리스 노트(`release-notes/vX.Y.Z.md`)를 참고해 맨 아래 `[vX.Y.Z 업데이트]` 섹션을 교체한다.
   (첫 문단의 핵심 가치 소개는 릴리스와 무관하게 유지한다)
2. 새 기능이 편의 기능/주요 기능으로 승격될 항목인지 확인한다.
   (업데이트 섹션은 다음 릴리스에서 사라지므로, 유지할 기능은 위 섹션으로 옮긴다)
3. Chrome / Firefox / Whale 대시보드의 설명(What's new 포함)에 붙여넣는다.
