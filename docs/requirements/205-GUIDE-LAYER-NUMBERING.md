# 205. 가이드·문구 문서 번호를 스펙과 같은 계층 번호로 바꾼다

```text
§205-1   배경
§205-2   만들 것
§205-3   완료 조건
§205-4   관련
```

## 205-1 배경

스펙은 계층 번호를 쓴다. 단일 문서 계층은 `N-NAME.md`(1-BACKGROUND, 4-DATA), 복수 문서 계층은 `N-M-NAME.md`(2-1, 2-2, 3-1, 3-2)이고 절 번호가 그 접두를 잇는다. #202에서 형식을 맞춘 가이드 8개와 문구 2개는 1~8 일련번호라 스펙과 같은 규칙으로 읽히지 않는다.

## 205-2 만들 것

- 가이드를 네 계층(1 릴리스, 2 스토어 배포, 3 문의 채널, 4 자산)으로 묶어 `1-`, `2-1`~`2-4`, `3-`, `4-1`~`4-2`로 이름·제목·절 번호를 바꾼다.
- 문구를 한 계층(1 배포 문구)으로 묶어 `1-1`, `1-2`로 바꾼다.
- 두 README의 읽는 순서 블록을 스펙 README와 같은 형식으로 쓴다.
- 링크·앵커·`가이드 §` 표기를 전부 갱신한다. 본문 내용과 게시 문구는 바꾸지 않는다.

## 205-3 완료 조건

- 옛 파일명 참조 0곳 (불변 문서 제외)
- 모든 번호 문서의 제목·절 번호가 파일명 번호와 일치
- `docs/` 아래 상대 링크·앵커 깨짐 0
- `npm run build`, `git diff --check` 통과
