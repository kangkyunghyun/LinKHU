필요한 사이트를 찾느라 탭과 검색 결과를 오가는 대신, 지금 하던 일의 흐름을 그대로 이어가세요.

01

이름만 입력하면 바로 찾기

서비스 이름, ID, 카테고리를 한 번에 검색합니다. / 키로 검색창에 바로 포커스하고 Enter로 첫 결과를 열 수 있어요.

/

서비스 목록을 불러오는 중입니다.

    내가 쓰는 것만,
    내 순서대로

    필요한 바로가기만 골라 드래그하면 나만의 메뉴가 완성됩니다.

    인포21
    e-Campus
    중앙도서관
    03

    손이 기억하는 단축키

    어느 페이지에 있든 단축키 한 번이면 LinKHU가 열립니다.

    macOS ⌘⇧L
    Windows Ctrl⇧L
