### Features

- 서비스 48개 추가. 지원 서비스가 117개에서 165개로 늘었습니다. 학생지원, 학사·교육·국제·후원, 문화·연구·행정 서비스와 h-STEM 융합전공을 등록했습니다
- 카테고리를 8개로 재편. `공통` 하나에 몰려 있던 서비스를 학사·포털, 생활·복지, 장학·진로·창업, 교육·역량, 캠퍼스·문화, 대학·행정으로 나눠 설정 페이지에서 원하는 서비스를 찾기 쉬워졌습니다
- 설정 페이지에 카테고리 필터 추가. 칩을 눌러 원하는 카테고리만 볼 수 있고, 목록은 3열로 넓어졌습니다. 드래그로 순서를 바꿀 때는 놓을 수 있는 영역을 드래그하는 동안에만 강조합니다
- 처음 설치했을 때 보이는 기본 바로가기를 자주 쓰는 10개로 줄였습니다. 이미 설정을 저장한 사용자의 목록과 순서는 그대로 유지됩니다
- 서비스 아이콘의 크기와 선 두께를 통일해 목록에서 아이콘이 들쭉날쭉하게 보이던 것을 정리했습니다
- 홈페이지를 휴대폰으로 열면 PC로 설치 링크를 옮기는 방법을 안내합니다

### Fixes

- iPadOS 사파리에서 홈페이지가 모바일로 인식되지 않던 문제를 고쳤습니다
- 홈페이지 카테고리 카드에 대학·행정이 빠져 있던 것을 채웠습니다
- 서비스 이름 `SW중심대학`을 `SW중심대학사업단`으로 정정했습니다

### Internal

- `category` 허용값을 3개에서 8개로 바꾸는 계약 변경. 스펙(§4-2) → 검증기 → 데이터 → 화면 순서로 반영했고, 저장 데이터는 서비스 id 기반이라 기존 사용자 목록에는 영향이 없습니다
- 기본 목록을 카테고리에서 분리해 `DEFAULT_SITE_IDS` 상수로 관리
- 설정 페이지의 드롭존과 필터 칩을 `SITE_CATEGORIES` 한 곳에서 렌더
- 홈페이지 GA4 연결 및 스토어 링크 클릭 이벤트 추가
- 스크립트 공용 유틸을 `scripts/lib.js`로 통합하고 죽은 코드 정리
- GitHub Actions 액션을 Node 24 대응 버전으로 갱신
- 릴리스 문구 작성 스킬과 커뮤니티 홍보 글 원본 추가, Chrome 배포 토큰 대응 문서화
