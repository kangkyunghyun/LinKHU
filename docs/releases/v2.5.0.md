### Features

- 시스템·라이트·다크 3단계 테마 추가. 헤더의 토글 버튼을 누르면 세 모드가 순서대로 바뀌고, 시스템 모드에서는 운영체제 설정을 따라갑니다
- 경희대학교 공식 색상(Kyung Hee Red, PANTONE 201C) 적용. 팝업·설정 페이지와 홈페이지의 브랜드 색을 공식 색상 체계로 통일했습니다
- 서비스 아이콘을 테마별로 두 벌 분리. 다크 테마에서 아이콘이 흰 사각형으로 보이던 문제 없이 또렷하게 표시됩니다
- 화면 아이콘을 통일된 세트로 교체하고, 설정 페이지의 이모지를 아이콘으로 정리했습니다. 설정 제목에는 LinKHU 로고가 표시됩니다
- 보조 설명 텍스트와 안내 링크의 명도 대비를 기준에 맞게 높였습니다
- 홈페이지의 지원 브라우저 표기를 3종 이상으로 확장했습니다

### Fixes

- 테마 저장에 실패했을 때 화면과 실제 저장된 값이 어긋나지 않도록 했습니다. 저장이 실패하면 이전 상태로 되돌리고 안내를 표시합니다
- 팝업과 설정 페이지를 함께 열어 둔 상태에서 한쪽의 테마를 바꾸면 다른 쪽에도 즉시 반영됩니다

### Internal

- 색상을 디자인 토큰으로 일원화하고, 텍스트용과 배경 채움용 주색을 역할별로 분리
- 다크 테마 아이콘 생성 스크립트 추가 및 두 벌 짝 검증을 빌드에 편입
- 제품 정의·설계 기준·데이터 스키마·디자인 규칙을 담은 `spec/` 문서 체계 신설
- 홈페이지에 남아 있던 구 브랜드 색 파생값 정리
- README를 사용자 중심으로 재구성하고 영어 버전 추가, 릴리스 절차와 스토어 설명을 별도 문서로 분리
