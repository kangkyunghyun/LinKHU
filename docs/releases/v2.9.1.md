### Fixes

- Firefox Add-ons에서 설치한 경우에도 새 버전 안내가 GitHub 릴리스 페이지로 연결되던 문제를 고쳤습니다. 이제 각 스토어 설치본은 스토어 업데이트를 따릅니다
- 팝업을 열면 현재 버전이 최신 버전 확인을 기다리지 않고 바로 보입니다
- 팝업의 단축키 안내가 아래 검색창과 카드보다 넓어 보이던 것을 고쳤습니다. 이제 양 끝이 맞습니다
- 서비스 이름의 오기 `아크&테크놀 러지융합전공`을 `아트&테크놀로지융합전공`으로 고치고, 카드에서 세 줄로 넘치던 이름을 줄였습니다
- 다크 모드에서 주색 버튼과 카드가 주변과 잘 구분되도록 색을 조금 밝혔습니다. 여러 창에서 테마를 바꿀 때 저장에 실패하면 엉뚱한 모드로 되돌아가던 문제도 고쳤습니다
- 홈페이지의 업데이트 내역을 불러오지 못하면 업데이트 링크가 GitHub 릴리스 페이지로 연결됩니다
