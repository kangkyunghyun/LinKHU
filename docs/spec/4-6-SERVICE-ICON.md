# 4-6 서비스 아이콘

이 문서는 서비스 아이콘의 크기와 형식, 팔레트, 라이트와 다크 두 벌 체계, 생성과 검증, SVG 원본, 추가와 변경 절차를 정한다.

아이콘 표시 크기는 레이아웃에, UI 아이콘 규칙은 UI 시스템에, 데이터의 아이콘 경로 형식과 삭제 절차는 데이터에, 그리는 절차와 실측한 도안 규칙(선 두께, 여백, 붉은색 비중)은 [서비스 아이콘 작업 가이드](../../.claude/skills/service-icon/SKILL.md)에 있다. ([4-1-1 팝업 영역](4-1-LAYOUT.md#4-1-1-팝업-영역), [4-2-4 UI 아이콘](4-2-UI-SYSTEM.md#4-2-4-ui-아이콘), [6-2-2 필드 규칙](6-2-DATA.md#6-2-2-필드-규칙), [6-2-5 변경 절차](6-2-DATA.md#6-2-5-변경-절차))

<br>

### 4-6-1 기본 규칙

| 항목 | 값 |
| --- | --- |
| 도안 | 팝업과 설정의 크기에서 한눈에 구분되는 단순한 상징 |
| 캔버스 | `70x70` |
| 배경 | 투명. 라이트와 다크 두 벌 모두 |
| 파일 형식 | 8비트, 비인터레이스 PNG. 16비트, 저비트 팔레트, 인터레이스 PNG는 생성기와 검증기가 거부해 빌드가 실패함 |
| 파일 이름 | 새 아이콘은 서비스 식별자와 맞춤 |
| 공유 | 전용 도안이 없는 서비스는 다른 서비스의 아이콘을 함께 써도 됨 |

<br>

### 4-6-2 팔레트

| 벌 | 쓰는 색 | 판정 기준 |
| --- | --- | --- |
| 라이트 | 브랜드 레드 `#a40f16`, 검정 `#1a1a1a`, 투명 | 흰 배경에 합성한 겉모습. 저장된 픽셀은 배경을 제거하며 역합성한 값이라 다름 |
| 다크 | 무채 선화 `#a1a1aa`, 붉은 계열 `#d94a52` | 다크 카드 `#161616` 위에서 각각 7.06:1, 4.35:1 |

| 규칙 | 내용 |
| --- | --- |
| 회색 채움 | 두지 않음. 면은 비운 채 선화로 표현 |
| 경계 안티에일리어싱 | 알파로만 표현. 팔레트 밖 색이나 목표색보다 밝은 픽셀을 만들지 않음 |
| 팔레트 밖의 색 | 추가하지 않음 |

<br>

### 4-6-3 두 벌 체계

| 벌 | 위치 | 만드는 방법 |
| --- | --- | --- |
| 라이트 | 확장 패키지의 서비스 아이콘 폴더 | 사람이 그림 |
| 다크 | 같은 하위 구조와 파일 이름으로 다크 전용 폴더 아래 | 생성기가 라이트에서 만듦. 손으로 고치지 않음 |

| 규칙 | 내용 |
| --- | --- |
| 데이터 | 라이트 경로만 적음. 다크 경로는 화면이 경로 규칙으로 만듦 |
| 고르는 기준 | 화면에 적용된 테마. 시스템 설정만 보는 마크업의 조건부 이미지 선택은 쓰지 않음 |
| 테마 변경 | 다시 그리지 않고 이미 그려진 아이콘의 경로만 바꿈 |
| 새 서비스 | 두 벌을 모두 만듦 |
| 아이콘 칸 | 배경이 투명하므로 표면 토큰을 그대로 씀 |

| 다크 벌 픽셀 변환 | 조건 | 알파 |
| --- | --- | --- |
| 투명 픽셀 | 알파 0 | 그대로 |
| `#d94a52` | 가장 큰 채널과 가장 작은 채널의 차가 40을 넘고 빨강이 가장 큼 | 가장 작은 채널이 120 미만이면 원본 알파 그대로. 가장 작은 채널이 기준 이상이면 `1 - (최소 채널 - 120) / 160`을 곱하되 0.35 아래로 내리지 않음. 반올림 |
| `#a1a1aa` | 나머지 | 원본 알파 × `1 - 밝기^0.45`를 반올림. 2 이하면 완전 투명으로 지움 |

<br>

### 4-6-4 생성과 검증

```mermaid
%%{init: {"flowchart": {"curve": "basis", "nodeSpacing": 24, "rankSpacing": 32}}}%%
flowchart LR
    A["`**라이트 원본**
사람이 그림`"] --> B["`**다크 아이콘 생성**
흰 배경 제거
다크 벌 생성
짝 없는 다크 삭제`"]
    B --> C["`**두 벌**`"]
    C --> D["`**짝 검증**
빌드에 포함`"]
    classDef comp fill:#E8F2E8,stroke:#527A59,color:#182D1D
    classDef store fill:#F5D9C9,stroke:#B97450,color:#452B1D
    class A,C store
    class B,D comp
```

| 생성 규칙 | 내용 |
| --- | --- |
| 라이트 원본 | 흰 배경을 걷어 내고 원본 파일을 고쳐 씀. 불투명 픽셀마다 알파를 `1 - 최소 채널 / 255`로 정하고 색은 `(채널 - (1 - 알파) × 255) / 알파`로 역합성해 반올림. 알파가 2/255 이하면 완전 투명으로 지움. 이미 반투명한 픽셀은 2/255 이하만 지우고 나머지는 그대로 둠 |
| 반복 실행 | 여러 번 돌려도 결과가 같음. 이미 투명한 원본도 색이 어긋나지 않음 |
| 짝 없는 다크 | 지움 |

| 짝 검증 | 막는 것 |
| --- | --- |
| 라이트마다 같은 자리의 다크 파일이 있음 | 다크 테마에서 깨지는 아이콘 |
| 라이트에 짝이 없는 다크 파일이 없음 | 지운 서비스의 다크 사본 |
| 다크 파일이 라이트로 다시 생성한 결과와 픽셀 단위로 같음. 알파가 0인 픽셀은 색을 비교하지 않음 | 손으로 고치거나 생성을 잊은 다크 파일 |
| 라이트 원본에 흰 배경이 없음 | 배경을 걷어 내지 않은 원본 |
| 두 벌 모두 네 모서리가 투명함. 알파 10/255까지 허용 | 배경이 남은 파일. 순백이 아닌 배경을 걷은 뒤 남는 잔여 알파 3~9는 허용 |

<br>

### 4-6-5 SVG 원본

| 규칙 | 내용 |
| --- | --- |
| 남기는 것 | 새로 그리는 아이콘의 SVG 원본. 색 규칙이 바뀌면 원본에서 다시 내보냄 |
| 위치 | 확장 패키지 밖. 패키지 폴더 안에 두면 사용자에게 배포됨 |
| 기존 아이콘 | SVG 원본이 없는 것도 있음 |
