# 4-5 상태

이 문서는 화면 밖에 보관하는 값의 목록과 성격, 읽고 쓰는 시점, 늦게 도착한 비동기 결과를 다루는 규칙을 정한다.

기본 목록은 정보 구조에, 테마의 되돌리기 기준은 테마에, 화면별 처리 순서는 인터랙션에, 저장 실패 시 화면 동작은 오류 처리에 있다. ([3-4 기본 목록](3-INFORMATION-ARCHITECTURE.md#3-4-기본-목록), [4-3-2 저장](4-3-THEME.md#4-3-2-저장), [6-1 인터랙션](6-1-INTERACTION.md), [7-1-3 저장소 실패](7-1-ERROR-HANDLING.md#7-1-3-저장소-실패))

서버가 없으므로 상태는 브라우저에만 남는다. 저장 키 이름은 이미 설치한 사용자의 값을 읽는 데 쓰이므로 바꾸지 않는다. 키를 늘리기 전에 사용자 설정인지 내부 캐시인지 먼저 정한다.

<br>

### 4-5-1 저장 키 목록

확장은 확장 로컬 저장소만 쓰고 동기화 저장소는 쓰지 않는다.

| 키 | 값 | 쓰는 곳 | 성격 |
| --- | --- | --- | --- |
| `userOrder` | 서비스 식별자 배열 | 설정의 저장 버튼에서 씀<br>팝업과 설정에서 읽음 | 사용자 설정 |
| `themeMode` | `"system"`, `"light"`, `"dark"` 중 하나 | 팝업과 설정의 테마 토글에서 씀<br>팝업과 설정에서 읽음 | 사용자 설정, 즉시 반영 |
| `shortcutNoticeDismissed` | `true` | 팝업에서 쓰고 읽음 | 사용자 설정, 즉시 반영 |
| `latestReleaseVersion` | 최신 릴리스 버전 문자열. 앞의 `v`를 뗀 값 | 팝업의 버전 안내 | 내부 캐시 |
| `latestReleaseVersionTime` | 위 값을 조회한 시각(ms) | 팝업의 버전 안내 | 내부 캐시 |

| 키 | 저장소 | 값 | 쓰는 곳 | 성격 |
| --- | --- | --- | --- | --- |
| `themeMode` | 랜딩 도메인의 영구 저장소 | `"system"`, `"light"`, `"dark"` 중 하나 | 랜딩 헤더 토글 | 사용자 설정, 즉시 반영. 확장의 같은 이름 키와 별개 |
| `linkhu-releases` | 랜딩 탭 세션 저장소 | 릴리스 목록 응답 JSON | 랜딩 업데이트 구역 | 내부 캐시. 탭을 닫으면 사라짐 |

<br>

### 4-5-2 사용자 설정과 내부 캐시

| 항목 | 사용자 설정 | 내부 캐시 |
| --- | --- | --- |
| 의미 | 사용자가 의도해서 만든 값 | 네트워크 호출을 줄이려는 파생 데이터 |
| 쓰는 시점 | 사용자 조작에서만 | 사용자 조작 없이 자동 |
| 저장 실패 | 사용자에게 알림 | 알리지 않음 |
| 값이 없을 때 | 기본값. `userOrder`는 기본 목록, `themeMode`는 `system` | 다시 조회해 채움 |

| 규칙 | 내용 |
| --- | --- |
| `userOrder` 저장 시점 | 설정의 저장 버튼에서만. 드래그 중에는 화면만 바뀜 |
| `userOrder`의 없는 식별자 | 그릴 때 거르고 저장된 값은 고쳐 쓰지 않음 |
| `userOrder`의 중복 식별자 | 한 번만 그림 |

<br>

### 4-5-3 즉시 반영형 설정

저장 버튼을 거치지 않는다. 저장에 실패하면 화면을 저장소와 같은 상태로 되돌리고 실패를 알린다.

| 키 | 고를 때 | 읽는 때 |
| --- | --- | --- |
| `themeMode` | 새 모드를 먼저 적용하고 저장함 | 화면을 열 때 |
| `shortcutNoticeDismissed` | 팝업 안내를 바로 숨기고 `true`를 저장함 | 단축키가 비어 있을 때만 |

<br>

### 4-5-4 비동기 결과의 순서

확장 저장소의 읽기와 쓰기는 비동기다. 쓰기 순서가 보장되어도 결과가 도착하는 순서는 보장되지 않는다.

| 위험 | 막는 방법 |
| --- | --- |
| 검색어를 빠르게 바꾸면 이전 읽기 결과가 나중에 도착해 최신 화면을 덮음 | 팝업은 그릴 때마다 렌더 번호를 새로 발급하고, 결과가 도착하면 자기 번호가 최신일 때만 그림 |
| 늦게 도착한 실패가 성공한 최신 저장을 되돌림 | 테마는 요청마다 증가하는 번호를 붙이고, 결과가 도착했을 때 최신 요청이 아니면 버림 |
| 다른 화면의 저장 알림이 방금 고른 값을 덮음 | 진행 중인 자기 쓰기가 있으면 외부 변경으로 덮지 않음 |
| 늦게 도착한 초기 읽기가 방금 고른 값을 덮음 | 읽는 사이 사용자가 고른 적이 있으면 화면은 그대로 두고 되돌릴 기준만 갱신함 |
