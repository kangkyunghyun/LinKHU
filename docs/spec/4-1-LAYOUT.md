# 4-1 레이아웃

이 문서는 팝업, 설정 페이지, 랜딩의 영역 순서와 문구, 치수, 설정 목록의 격자, 팝업 카드 이름의 줄바꿈을 정한다.

색, 여백, 반경, 글자 크기 토큰은 UI 시스템에, 대비 기준은 테마에, 카테고리 목록과 각 화면이 무엇을 보여주는지는 정보 구조에, 상태와 실패 문구는 오류 처리에 있다. ([4-2-2 디자인 토큰 규칙](4-2-UI-SYSTEM.md#4-2-2-디자인-토큰-규칙), [4-3-5 대비 기준](4-3-THEME.md#4-3-5-대비-기준), [3-2 카테고리](3-INFORMATION-ARCHITECTURE.md#3-2-카테고리), [3-3 화면별 범위](3-INFORMATION-ARCHITECTURE.md#3-3-화면별-범위), [7-1 오류 처리](7-1-ERROR-HANDLING.md))

### 4-1-1 팝업 영역

팝업은 세로로만 쌓는다. 숨김 영역은 높이가 0이고 열리면 아래 영역을 민다.

| 순서 | 영역 | 내용 | 평소 상태 |
| --- | --- | --- | --- |
| 1 | 헤더 | 왼쪽: 제목 "LinKHU", 현재 버전 "v{버전}", 업데이트 안내 "새 업데이트"<br>오른쪽: 테마 전환 버튼, 설정 버튼 | 보임. 업데이트 안내는 새 버전이 있을 때만 |
| 2 | 단축키 안내 | "단축키 미설정", 버튼 "설정에서 지정", 닫기 "×" | 숨김. 단축키가 비어 있고 닫은 적 없을 때만 보임 |
| 3 | 검색창 | 왼쪽 돋보기, 자리표시 "서비스 검색" | 보임 |
| 4 | 빈 결과 문구 | "검색 결과 없음" | 숨김. 보여줄 카드가 없을 때만 보임 |
| 5 | 상태 줄 | 테마 변경 알림, 테마나 안내 닫기의 저장 실패 | 스크린 리더만 읽음. 저장 실패일 때만 화면에 보임 |
| 6 | 카드 격자 | 3열 고정. 카드마다 아이콘과 이름 | 보임 |
| 7 | 푸터 | 가운데 정렬 "홈페이지 · 문의하기" | 보임 |
| 8 | 문의 패널 | 문의 입력 영역 | 숨김. 푸터의 문의하기로 펼치고 접음 |

| 자리 | 값 |
| --- | --- |
| 팝업 폭 | `320px` 고정 |
| 글꼴 | Noto Sans KR. 글꼴 파일은 싣지 않음 |
| 바깥 여백 | 사방 `20px` |
| 제목 | `20px`, 굵게, 주색 |
| 현재 버전 | 보조 문구 크기, 보조 텍스트 색, 제목과 `8px` 간격 |
| 헤더 버튼 | 아이콘 `20px`, 안쪽 여백 `4px`, 버튼 사이 `4px` |
| 검색창 | 높이 `36px`. 안쪽 여백 왼쪽 `32px`, 오른쪽 `12px`. 바깥 좌우 `4px` |
| 카드 격자 | 칸 사이 `12px`. 내용 최대 높이 `300px`, 안쪽 여백까지 `308px`. 넘으면 세로 스크롤 |
| 세로 스크롤바 | Chromium 계열 `6px`. Firefox는 플랫폼 폭 |
| 카드 | 높이 `90px` 고정. 안쪽 여백 위아래 `8px`, 좌우 `4px`. 테두리 `1px`. 반경 `12px` |
| 카드 아이콘 | `40×40px` |
| 카드 이름 | `12px`, 중간 굵기, 자간 `-0.5px`, 줄 높이 1.25. 두 줄까지 보이고 넘치면 말줄임 |
| 영역 사이 | 헤더 아래 `8px`, 검색창 아래 `8px`, 푸터 위 `12px`, 문의 패널 위 `12px` |
| 빈 결과 문구 위아래 | `24px` |

| 카드 상태 | 표현 |
| --- | --- |
| 평소 | 올린 표면색, 기본 테두리, 카드 그림자 |
| hover | `3px` 위로 뜸. 주색 테두리, 주색 그림자 |
| 누름 | `0.98`배로 줄어듦 |
| 전환 | `0.2s` |

**1. 문의 입력 영역**

팝업과 설정의 문의 패널, 랜딩의 문의 대화상자는 내부 순서가 같다.

| 순서 | 요소 | 내용 |
| --- | --- | --- |
| 1 | 문의 유형 칩 | 입력창 위 한 줄. 칩 사이 `8px`. 팝업 320px 안에서도 칩 세 개가 줄바꿈 없이 들어감 |
| 2 | 문의 본문 | 여러 줄 입력. 자리표시 "불편한 점이나 추가하고 싶은 서비스를 적어주세요." 확장 3줄, 랜딩 4줄 |
| 3 | 답변받을 이메일 | 선택 입력. 자리표시 "답변 받을 이메일 (선택)" |
| 4 | 보내기 | 버튼 "보내기" |
| 5 | 상태 | 입력 검증과 전송 결과 문구. 오른쪽 정렬, 보조 문구 크기 |

### 4-1-2 설정 영역

설정 페이지는 탭으로 열리는 화면 그 자체다. 컨테이너에 그림자나 큰 모서리를 주지 않고, 폭 상한 때문에 생기는 좌우 여백도 콘텐츠와 같은 색으로 칠한다.

| 순서 | 영역 | 내용 | 평소 상태 |
| --- | --- | --- | --- |
| 1 | 헤더 | 확장 로고 `26px`와 제목 "LinKHU 설정"<br>안내 "원하는 사이트를 오른쪽 '내 바로가기'로 드래그하세요."<br>링크 "홈페이지", "문의하기", 테마 전환 버튼 | 보임 |
| 2 | 문의 패널 | 헤더 아래에 떠 있는 패널 | 숨김. 헤더의 문의하기로 펼치고 접음 |
| 3 | 단축키 안내 | 제목 "단축키가 설정되어 있지 않습니다."와 브라우저별 단축키 설정 주소 | 숨김. 단축키가 비어 있을 때만 보임 |
| 4 | 왼쪽 단 | 제목 "사용 가능한 사이트"<br>검색창 "서비스 검색", 카테고리 필터, 빈 결과 문구 "조건에 맞는 서비스가 없습니다", 카테고리 묶음 격자 | 보임. 빈 결과 문구는 검색어나 필터가 걸리고 결과가 0건일 때만 |
| 4 | 오른쪽 단 | 제목 "내 바로가기 (활성화됨)". 한 열. 드래그로 담기와 순서 바꾸기 | 보임 |
| 5 | 저장 버튼 | "변경사항 저장하기". 두 단 아래 한 곳에만 | 보임 |
| 6 | 상태 줄 | 테마 변경 알림, 테마 저장 실패 | 스크린 리더만 읽음. 테마 저장 실패일 때만 화면에 보임 |

| 자리 | 값 |
| --- | --- |
| 화면 높이 | 창 높이 전체, 최소 `500px` |
| 폭 상한 | `min(96vw, 1440px)`, 가운데 정렬 |
| 바깥 여백 | 위아래 `16px`, 좌우 `24px` |
| 헤더 | 요소 사이 `12px`, 아래 `12px`. 안내 문구가 남는 폭을 차지함 |
| 헤더 링크 | 본문 크기, 보조 텍스트 색. hover에 주색과 밑줄 |
| 헤더 아이콘 버튼 | 아이콘 `20px`, 안쪽 여백 `8px` |
| 두 단 사이 | `20px` |
| 각 단 | 모서리 `8px`, 안쪽 `16px`, 가라앉은 표면색 |
| 단 제목 | 가운데 정렬, 아래 `2px` 선 |
| 목록 항목 | 높이 `46px`, 안쪽과 사이 `8px` |
| 검색창과 필터 | 세로로 쌓고 사이 `8px`, 목록과 `12px` |

### 4-1-3 설정 페이지 목록

**1. 열 수와 폭 비율**

왼쪽은 카테고리 묶음마다 격자로 깔고, 오른쪽 내 바로가기는 한 열을 유지한다. 오른쪽의 놓을 자리는 포인터의 세로 좌표로만 정한다.

| 창 폭 | 왼쪽 열 수 | 왼쪽:오른쪽 |
| --- | --- | --- |
| 1280px 초과 | 3 | 3 : 1 |
| 900px 초과 1280px 이하 | 2 | 2 : 1 |
| 900px 이하 | 1 | 1 : 1 |

<br>

**2. 목록 항목**

| 순서 | 요소 | 규칙 |
| --- | --- | --- |
| 1 | 드래그 손잡이 | `18px` 아이콘, 보조 텍스트 색 |
| 2 | 서비스 아이콘 | `24px` |
| 3 | 이름 | 공백을 모두 지우고 보임. 한 줄, 넘치면 말줄임 |
| 4 | 새 탭 링크 | 오른쪽 끝. `16px` 아이콘에 안쪽 여백 `4px`로 클릭 대상 `24×24`. 평소에도 자리를 차지함. 접근성 이름 "{원래 이름} 새 탭에서 열기" |

| 새 탭 링크 상태 | 색 |
| --- | --- |
| 평소 | 보조 텍스트 색. 투명도로 흐리게 하지 않음 |
| hover, 키보드 포커스 | 주색 |

<br>

**3. 카테고리 묶음과 필터**

| 규칙 | 내용 |
| --- | --- |
| 원본 | 묶음과 필터 칩은 카테고리 목록 하나에서 만듦. 카테고리마다 묶음 하나, 칩 하나 |
| 묶음 | 카테고리 이름을 머리글로 두고 그 아래 항목 격자 |
| 필터 칩 | 검색창 아래 줄에 두고 넘치면 줄을 바꿈. 접거나 드롭다운으로 감추지 않음 |

### 4-1-4 팝업 카드 이름

**1. 한 줄에 들어가는 글자 수**

Chromium 계열 기준으로 팝업 폭 320px에서 차례로 뺀다.

| 빼는 것 | 값 | 남는 폭 |
| --- | --- | --- |
| 팝업 바깥 좌우 여백 (20 × 2) | 40 | 280 |
| 카드 격자 좌우 안쪽 여백 (4 × 2) | 8 | 272 |
| 세로 스크롤바 | 6 | 266 |
| 3열 사이 간격 (12 × 2) | 24 | 242 |
| **3열로 나눈 카드 한 칸** | ÷ 3 | **80.67** |
| 카드 좌우 테두리 (1 × 2) | 2 | 78.67 |
| 카드 좌우 안쪽 여백 (4 × 2) | 8 | **70.67** |

| 환경 | 한 줄 폭 |
| --- | --- |
| 스크롤바 없음 | 72.67px |
| Firefox, 스크롤바 15px | 67.67px |
| 데이터 검증 기준 | 70.6px |

| 글자 | 검증이 잡는 폭 |
| --- | --- |
| 한글 | 11.5px. 12px에서 자간 0.5px를 뺀 안전 상한 |
| 영문, 숫자 | 6.7px |
| 그 밖 | 4.7px |

한글은 한 줄에 6자(69px)가 들어간다. 카드 폭이나 글자 크기를 바꾸면 아래 줄바꿈 표와 검증 기준 폭을 함께 고친다.

| 규칙 | 내용 |
| --- | --- |
| 글자 크기 | 최대 12px. 12.5px이면 여섯 자가 한 줄을 넘음 |
| 테두리 | 폭 계산에 넣음 |
| 이름 칸 여백 | 좌우 여백을 따로 두지 않음 |
| 꺾는 방식 | 어절 단위로 꺾고, 꺾을 자리가 없으면 글자 사이 아무 데서나 꺾음 |

<br>

### 4-1-5 랜딩

**1. 페이지 틀**

| 자리 | 값 |
| --- | --- |
| 본문 폭 | `min(100% - 48px, 1180px)`. 700px 이하에서 `100% - 32px` |
| 최소 폭 | `320px` |
| 글꼴 | Pretendard, 시스템 글꼴, Noto Sans KR 순. 본문 `16px`, 줄 높이 1.65, 어절 단위 줄바꿈 |
| 헤더 | 화면 위에 붙음. 높이 `76px`(700px 이하 `68px`). 반투명 배경과 흐림 |
| 앵커 이동 | 부드럽게 스크롤. 위 여백 `96px` |
| 키보드 포커스 | `3px` 포커스 색 윤곽선, 간격 `4px` |
| 첫 요소 | "본문으로 바로가기" 스킵 링크. 포커스를 받을 때만 왼쪽 위에 나타남 |
