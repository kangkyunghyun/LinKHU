# 4-1. 레이아웃

두 화면의 영역 배치와 치수를 고정한다. 여기 적힌 값이 정본이며 CSS는 이를 구현한다.

팝업 레이아웃의 핵심 제약은 **320px 고정 폭**이다. 이 폭이 카드 열 수, 글자 크기, 줄바꿈 표를 차례로 결정한다.

```text
§4-1-1   팝업 영역          320px 안의 세로 순서
§4-1-2   설정 영역          2단 판과 저장 버튼
§4-1-3   설정 페이지 목록     열 수, 카드 크기, 새 탭 링크, 카테고리 영역
§4-1-4   팝업 카드 이름       한 줄 6자, 줄바꿈 표
```

## 4-1-1 팝업 영역

팝업은 320px 고정이다. 세로로만 쌓이며 순서는 다음과 같다.

| 순서 | 영역 | 내용 | 평소 상태 |
| --- | --- | --- | --- |
| 1 | `header` | 제목·버전·업데이트 안내 / 테마 토글 · 설정 버튼 | 항상 |
| 2 | 단축키 안내 | 설정으로 가는 한 줄 안내 | **숨김** — 미등록이고 닫은 적 없을 때만 |
| 3 | 검색창 | | 항상 |
| 4 | 상태 줄 | 검색 결과 없음 / 저장 실패 | 빈 줄 |
| 5 | 카드 격자 | 3열 | 항상 |
| 6 | 문의 패널 | 문의 입력과 전송 | **숨김** — 푸터 토글로 펼침 |
| 7 | `footer` | 홈페이지 · 문의하기 | 항상 |

**320px 안에 무엇을 넣을지가 모든 치수를 정한다.**

| 자리 | 값 | 왜 |
| --- | --- | --- |
| 바깥 여백 | 사방 `20px` | 남는 `280px`을 카드 3열이 나눠 갖는다 |
| 검색창 높이 | `36px` | 한 줄짜리 컨트롤이다 |
| 검색창 안쪽 여백 | 왼쪽 `32px`, 오른쪽 `12px` | 왼쪽은 돋보기가 앉는 자리다 |
| 카드 격자 | 3열, 칸 사이 `12px` | |
| 격자 높이 | 최대 `300px`, 넘으면 스크롤 | 더 길어지면 도구가 아니라 페이지가 된다 |
| 세로 스크롤바 | `6px` | **이 폭이 카드 한 줄 글자 수를 바꾼다** (§4-1-4) |
| 카드 높이 | `90px` 고정 | 이름 길이와 무관하게 같은 크기 |
| 카드 아이콘 | `40×40px` | 설정(`24px`)보다 크다. 팝업은 아이콘으로 고르는 화면이다 |
| 영역 사이 간격 | 붙는 것 `8px`, 끊는 것 `12px` | 헤더-검색창은 `8px`, 푸터 위는 `12px` |

| 규칙 | 내용 |
| --- | --- |
| 카드 격자 | **3열 고정.** 열 수를 바꾸면 카드 폭 계산과 줄바꿈 표를 전부 다시 정해야 한다 |
| 숨김 영역 | 단축키 안내와 문의 패널은 **자리를 미리 차지하지 않는다.** 숨김 상태의 높이가 0이고 열릴 때 아래가 밀린다 |
| 상태 줄 | 내용이 바뀔 때마다 스크린 리더가 읽는 상태 영역이다. 검색 결과 없음, 저장 실패 같은 **짧은 사실 하나**만 싣는다 |

## 4-1-2 설정 영역

설정은 탭으로 열린다(`open_in_tab: true`). 팝업과 달리 폭이 넉넉하므로 2단으로 나눈다.

| 영역 | 내용 |
| --- | --- |
| `header` | 제목 · 테마 선택 · 문의 |
| 단축키 안내 | **숨김** — 미등록일 때만 |
| 본문 왼쪽 — 사용 가능한 사이트 | 검색창 + 카테고리 필터, 그 아래 카테고리 영역(격자) |
| 본문 오른쪽 — 내 바로가기 | 한 열, 드래그로 담기·순서 바꾸기 |
| 저장 버튼 | 변경사항 저장하기 |

**설정은 떠 있는 카드가 아니라 화면 그 자체다.**

| 자리 | 값 | 왜 |
| --- | --- | --- |
| 화면 높이 | `100vh`, 최소 `500px` | 세로를 채운다 |
| 폭 상한 | `min(96vw, 1440px)` | 넓은 모니터에서 글줄이 길어지지 않게 |
| 바깥 여백 | 위아래 `16px`, 좌우 `24px` | |
| 두 단 사이 | `20px` | |
| 각 단 | 모서리 `8px`, 안쪽 `16px`, 가라앉은 표면색 | |
| 단 제목 | 가운데 정렬, 아래 `2px` 선 | 목록과 끊어 준다 |
| 목록 항목 | 높이 `46px` 고정, 안쪽·사이 `8px` | 팝업 카드와 같다. 이름 길이와 무관하게 같은 크기 |
| 검색창과 필터 | 세로로 쌓고 사이 `8px`, 목록과 `12px` | 카테고리가 여덟 개라 한 줄에 안 들어간다 |

- **저장 버튼은 두 단 아래 한 곳에만 둔다**. 저장은 사용자가 확정하는 행위이고, 확정 지점이 여러 개면 무엇이 저장됐는지 알 수 없다.

## 4-1-3 설정 페이지 목록

서비스가 늘어날수록 세로로만 쌓는 배치는 훑기 어려워지므로, 왼쪽 "사용 가능한 사이트"는 격자로 깐다.

### 열 수와 폭 비율

- 왼쪽 목록은 격자, 오른쪽 '내 바로가기'는 **한 열을 유지한다**. 오른쪽의 드롭 위치 계산이 포인터의 세로 좌표만 보기 때문이다. 오른쪽을 격자로 만들면 순서 바꾸기가 어긋난다.
- 두 열의 폭 비율은 **왼쪽 격자의 열 수에 맞춘다**. 양쪽 카드 크기가 비슷해야 같은 종류의 항목으로 읽힌다.

| 창 폭 | 왼쪽 열 수 | 왼쪽:오른쪽 |
| --- | --- | --- |
| 1280px 초과 | 3 | 3 : 1 |
| 900px 초과 1280px 이하 | 2 | 2 : 1 |
| 900px 이하 | 1 | 1 : 1 |

비율은 두 단에 몫을 나눠 주어 만든다. **왼쪽 열 수를 그대로 왼쪽 몫으로 쓰고 오른쪽은 항상 1이다.** 그래야 양쪽 카드가 계속 비슷한 크기로 보인다.

### 카드 크기

- 항목 카드는 **이름 길이와 무관하게 같은 크기다**. 높이를 고정하고, 넘치는 이름은 말줄임표로 자른다. 카드가 들쭉날쭉하면 격자의 훑기 이점이 사라진다.

### 항목 안의 새 탭 링크

목록 항목 오른쪽 끝에 그 서비스를 새 탭으로 여는 링크를 둔다. 왼쪽 목록과 오른쪽 '내 바로가기' 양쪽에 같은 형태로 붙는다.

- 링크는 **평소에도 자리를 차지한다**. 커서를 올렸을 때만 나타나게 하면 커서가 들고 날 때마다 이름이 쓸 수 있는 폭이 바뀌어 말줄임 위치가 흔들린다.
- **반투명으로 흐리게 만들지 않는다**. `opacity`로 낮추면 합성 후 대비가 컨트롤의 3:1 기준을 넘지 못한다. `--color-text-muted`를 0.35로 적용하면 라이트 1.66:1, 다크 1.95:1이다. 덜 두드러지게 하려면 투명도 대신 **색을 낮춘다.** 기본은 `--color-text-muted`(라이트 5.74:1, 다크 7.06:1), hover와 `:focus-visible`에서는 `--color-primary`다.

### 섹션 구분

- 왼쪽 목록의 영역과 필터 칩은 **`src/data.js`의 `SITE_CATEGORIES` 하나에서 렌더한다**. 마크업에 카테고리를 박아두면 데이터와 화면이 갈라진다.
- 영역 순서는 배열 순서를 따른다. 카테고리마다 영역 하나, 칩 하나다.
- **카테고리 안에 다시 소제목을 두지 않는다**. 구분이 필요하면 카테고리를 늘린다. 소제목과 카테고리가 겹치면 사용자는 같은 목록에 두 계층의 분류를 보게 된다.
- 카테고리가 늘어 칩을 검색창 옆에 나란히 둘 수 없으면 **검색창 아래 줄로 내리고 줄바꿈한다.** 칩을 접거나 드롭다운으로 감추지 않는다 — 한눈에 보이는 것이 칩의 이점이다.

### 화면 여백

- 설정 페이지는 **떠 있는 카드가 아니라 화면 그 자체다**. 컨테이너에 그림자나 큰 모서리를 주지 않고, 세로는 화면을 채운다.
- 폭 상한 때문에 생기는 좌우 여백은 **콘텐츠와 같은 색이어야 한다**. 다른 색 띠로 보이면 페이지가 종이 위에 얹힌 것처럼 읽힌다.

## 4-1-4 팝업 카드 이름

팝업 카드의 이름 칸은 **두 줄까지만 보이고**(`-webkit-line-clamp: 2`), 넘치면 말줄임된다.

### 한 줄에 들어가는 글자 수

팝업 폭 320px에서 다음을 순서대로 뺀다.

| 빼는 것 | 값 | 남는 폭 |
| --- | --- | --- |
| `.container` 좌우 패딩 (20 × 2) | 40 | 280 |
| `.grid-container` 좌우 패딩 (4 × 2) | 8 | 272 |
| 세로 스크롤바 | 6 | 266 |
| 3열 사이 gap (12 × 2) | 24 | 242 |
| **3열로 나눈 카드 한 칸** | ÷ 3 | **80.67** |
| `.grid-item` 좌우 테두리 (1 × 2) | 2 | 78.67 |
| `.grid-item` 좌우 패딩 (4 × 2) | 8 | **70.67** |

한 줄 가용 폭은 70.67px이다. 스크롤바가 없으면 6px이 3열로 나뉘어 칸마다 2px씩 넓어져 72.67px이 된다. 글자는 12px에 `letter-spacing: -0.5px`라 한글 한 자가 11.5px이므로, **한 줄에 한글 6자**다(69px).

- **카드 라벨의 글자 크기는 최대 12px이다**. 12.5px이면 여섯 자가 72px이 되어 한 줄에 들어가지 않는다. 줄바꿈 표도 전부 다시 정해야 한다. 이 값은 취향이 아니라 폭이 정하므로 글자 크기 스케일에서도 고정한다.
- **`.grid-item`의 테두리를 빼먹지 않는다.** `box-sizing: border-box`라 1px 테두리 두 개가 글자 폭에서 그대로 빠진다. 빠뜨리면 폭을 2px 넓게 잡게 되고, 표에 넣어 둔 이름이 말줄임된다.
- **`.grid-item span`에는 좌우 패딩을 두지 않는다**. 카드가 이미 좌우 4px을 넣어주므로 겹치는 여백이고, 스케일상 다음 단계인 4px을 주면 글자 폭이 62.67px로 좁아져 여섯 자가 들어가지 않는다.

이 폭 계산이 이 절의 모든 규칙의 근거다. 카드 폭이나 글자 크기를 바꾸면 아래 규칙과 `scripts/validate-data.js`의 `CARD_LINE_WIDTH_PX`를 함께 고쳐야 한다.

### 줄바꿈 지점은 표로 관리한다

- 공백이 있는 이름은 `word-break: keep-all`이 **어절 단위로 꺾는다.** 표에 넣지 않는다.
- 공백이 없는 긴 이름은 꺾을 자리가 없어 `overflow-wrap: anywhere`가 발동하고, **글자 사이 아무 데서나 꺾인다**(`글로벌교육지 / 원팀`). 이런 이름은 `src/shared.js`의 `CARD_LINE_BREAKS`에 id → 첫 줄로 적고, `cardDisplayName`이 그 지점에 ZWSP(`U+200B`)를 넣는다.
- **표는 `src/shared.js`에 둔다**. 줄바꿈 지점은 카드 폭에 딸린 표현 문제이지 데이터가 아니다. `src/data.js`에 넣으면 다섯 필드 계약을 건드리게 된다.
- `overflow-wrap: anywhere`는 **fallback으로 남긴다**. 빼면 표에 없는 이름이 한 줄로 말줄임돼 뒷부분이 사라진다.
- 두 줄(6자 × 2)에도 들어가지 않는 이름은 꺾지 않고 현재 동작(글자는 모두 보임)을 유지한다. 의미 단위로 꺾으면 둘째 줄이 말줄임돼 오히려 글자가 사라지기 때문이다. 모르고 빠진 것이 아님을 남기려고 `WIDE_CARD_NAMES`에 명시한다.
- 공백 없는 이름이 한 줄 폭을 넘는데 표에도 예외 목록에도 없으면 `npm run validate:data`가 **실패한다**. 서비스를 추가할 때 자동으로 걸려 표가 썩지 않는다.
- **표에 있는 이름은 갈라진 두 줄이 각각 한 줄 폭에 들어가야 한다**. 이것도 `validate:data`가 검사한다. "한 줄을 넘는가"만 보면 표에 넣어 둔 항목이 조용히 말줄임되는 것을 놓친다.

### 접미사 규칙을 쓰지 않는 이유

"학과·센터·팀 앞에서 꺾는다" 같은 규칙으로 표를 대신하고 싶어지지만, **쓰지 않는다**. 올바른 지점은 형태소만으로 정해지지 않고 **두 줄의 길이 균형까지 봐야** 정해진다.

`국제통상금융투자학부`가 그 사례다. 접미사 규칙대로 `국제통상금융투자 / 학부`로 꺾으면 첫 줄이 8자라 한 줄에 들어가지 않아 다시 아무 데서나 꺾인다. 실제로 필요한 지점은 `국제통상 / 금융투자학부`이며, 이것은 접미사가 아니라 **첫 줄이 6자 안에 들어가는가**를 보고 정한 것이다. 규칙 하나로 덮으려 하면 이런 이름마다 예외가 붙어, 결국 표보다 읽기 어려운 규칙이 된다.

이름이 공백을 넣어 고칠 수 있는 경우라면 **표보다 데이터 정정이 낫다.** `환경학및환경공학과`는 `환경학 및 환경공학과`로 고쳐 `keep-all`이 처리하게 했다.
