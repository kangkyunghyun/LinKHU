# 4-1. 레이아웃

이 문서는 팝업과 설정 페이지의 영역 순서와 치수, 설정 목록의 격자, 팝업 카드 이름의 줄바꿈을 정한다.

색, 여백, 반경, 글자 크기 토큰은 UI 시스템에, 각 화면이 무엇을 보여주는지는 정보 구조에 있다. ([4-2-2 디자인 토큰 규칙](4-2-UI-SYSTEM.md#4-2-2-디자인-토큰-규칙), [3-3 화면별 범위](3-INFORMATION-ARCHITECTURE.md#3-3-화면별-범위))

팝업 레이아웃의 기준은 **320px 고정 폭**이다. 이 폭이 카드 열 수, 글자 크기, 줄바꿈 표를 차례로 정한다.

<br>

## 4-1-1 팝업 영역

팝업은 세로로만 쌓는다.

| 순서 | 영역 | 내용 | 평소 상태 |
| --- | --- | --- | --- |
| 1 | 헤더 | 제목, 버전, 업데이트 안내<br>테마 전환 버튼, 설정 버튼 | 보임 |
| 2 | 단축키 안내 | 설정으로 가는 한 줄 안내 | 숨김<br>단축키가 비어 있고 닫은 적 없을 때만 보임 |
| 3 | 검색창 | | 보임 |
| 4 | 빈 결과 문구 | 검색 결과 없음 | 숨김<br>보여줄 카드가 없을 때만 보임 |
| 5 | 상태 줄 | 테마 변경 알림, 테마나 안내 닫기의 저장 실패 | 화면에서 숨기고 스크린 리더만 읽음<br>저장 실패일 때만 보임 |
| 6 | 카드 격자 | 3열 | 보임 |
| 7 | 푸터 | 홈페이지, 문의하기 | 보임 |
| 8 | 문의 패널 | 문의 유형 선택, 입력과 전송 | 숨김<br>푸터의 문의하기로 펼침 |

| 자리 | 값 | 이유 |
| --- | --- | --- |
| 바깥 여백 | 사방 `20px` | 남는 `280px`을 카드 3열이 나눠 쓴다 |
| 검색창 높이 | `36px` | 한 줄짜리 컨트롤 |
| 검색창 안쪽 여백 | 왼쪽 `32px`, 오른쪽 `12px` | 왼쪽은 돋보기 자리 |
| 카드 격자 | 3열, 칸 사이 `12px` | |
| 격자 높이 | 최대 `300px`, 넘으면 스크롤 | 더 길어지면 도구가 아니라 페이지가 된다 |
| 세로 스크롤바 | `6px` | 이 폭이 카드 한 줄 글자 수를 바꾼다 |
| 카드 높이 | `90px` 고정 | 이름 길이와 무관하게 같은 크기 |
| 카드 아이콘 | `40×40px` | 설정 목록(`24px`)보다 크다. 팝업은 아이콘으로 고르는 화면이다 |
| 영역 사이 간격 | 이어지는 영역 `8px`, 끊는 영역 `12px` | 헤더와 검색창 사이 `8px`, 푸터 위 `12px` |

| 규칙 | 내용 |
| --- | --- |
| 카드 격자 | 3열로 고정한다. 열 수를 바꾸면 카드 폭 계산과 줄바꿈 표를 전부 다시 정한다 |
| 숨김 영역 | 단축키 안내와 문의 패널은 숨김 상태에서 높이가 0이다. 열릴 때 아래 영역이 밀린다 |
| 문의 패널 위치 | 푸터 아래에 펼친다. 누른 문의하기 버튼이 제자리에 남는다 |
| 상태 줄 | 내용이 바뀔 때마다 스크린 리더가 읽는 상태 영역이다. 모드 변경은 아이콘과 화면 색이 이미 보여주므로 글자는 저장 실패일 때만 화면에 드러낸다. 짧은 사실 하나만 싣는다 |

<br>

**1. 문의 입력 영역**

팝업과 설정의 문의 패널, 랜딩의 문의 대화상자는 내부 순서가 같다.

| 순서 | 요소 | 배치 |
| --- | --- | --- |
| 1 | 문의 유형 칩 | 입력창 위 한 줄. 팝업 320px 안에서도 칩 세 개가 줄바꿈 없이 들어감 |
| 2 | 문의 본문 | 여러 줄 입력창 |
| 3 | 답변받을 이메일 | 선택 입력란 |
| 4 | 보내기 | 전송 버튼 |
| 5 | 상태 | 입력 검증과 전송 결과 문구 |

<br>

## 4-1-2 설정 영역

설정 페이지는 탭으로 열린다. 폭이 넉넉하므로 두 단으로 나눈다.

| 순서 | 영역 | 내용 |
| --- | --- | --- |
| 1 | 헤더 | 제목, 사용 안내 문구<br>홈페이지, 문의하기, 테마 전환 버튼<br>문의하기를 누르면 헤더 아래에 떠 있는 문의 패널 |
| 2 | 단축키 안내 | 숨김. 단축키가 비어 있을 때만 보임 |
| 3 | 왼쪽 단, 사용 가능한 사이트 | 검색창과 카테고리 필터, 그 아래 카테고리 묶음 격자 |
| 3 | 오른쪽 단, 내 바로가기 | 한 열. 드래그로 담기와 순서 바꾸기 |
| 4 | 저장 버튼 | 변경사항 저장하기 |

설정 페이지는 떠 있는 카드가 아니라 화면 그 자체다. 컨테이너에 그림자나 큰 모서리를 주지 않고 세로는 화면을 채운다. 폭 상한 때문에 생기는 좌우 여백은 콘텐츠와 같은 색이다. 다른 색 띠로 보이면 페이지가 종이 위에 얹힌 것처럼 읽힌다.

| 자리 | 값 | 이유 |
| --- | --- | --- |
| 화면 높이 | `100vh`, 최소 `500px` | 세로를 채운다 |
| 폭 상한 | `min(96vw, 1440px)` | 넓은 모니터에서 글줄이 길어지지 않게 한다 |
| 바깥 여백 | 위아래 `16px`, 좌우 `24px` | |
| 두 단 사이 | `20px` | |
| 각 단 | 모서리 `8px`, 안쪽 `16px`, 가라앉은 표면색 | |
| 단 제목 | 가운데 정렬, 아래 `2px` 선 | 목록과 끊어 준다 |
| 목록 항목 | 높이 `46px` 고정, 안쪽과 사이 `8px` | 팝업 카드처럼 이름 길이와 무관하게 같은 크기 |
| 검색창과 필터 | 세로로 쌓고 사이 `8px`, 목록과 `12px` | 카테고리가 여덟 개라 한 줄에 들어가지 않는다 |

저장 버튼은 두 단 아래 한 곳에만 둔다. 저장은 사용자가 확정하는 행위이고, 확정 지점이 여러 개면 무엇이 저장됐는지 알 수 없다.

<br>

## 4-1-3 설정 페이지 목록

서비스가 늘수록 세로로만 쌓는 배치는 훑기 어려우므로 왼쪽 사용 가능한 사이트는 격자로 깐다.

<br>

**1. 열 수와 폭 비율**

오른쪽 내 바로가기는 한 열을 유지한다. 드롭 위치 계산이 포인터의 세로 좌표만 보므로 오른쪽을 격자로 만들면 순서 바꾸기가 어긋난다.

| 창 폭 | 왼쪽 열 수 | 왼쪽:오른쪽 |
| --- | --- | --- |
| 1280px 초과 | 3 | 3 : 1 |
| 900px 초과 1280px 이하 | 2 | 2 : 1 |
| 900px 이하 | 1 | 1 : 1 |

왼쪽 열 수를 왼쪽 단의 너비 비율로 쓰고 오른쪽은 항상 1이다. 그래야 양쪽 카드가 비슷한 크기로 보여 같은 종류의 항목으로 읽힌다.

<br>

**2. 카드 크기**

항목 카드는 이름 길이와 무관하게 같은 크기다. 높이를 고정하고 넘치는 이름은 말줄임표로 자른다. 카드가 들쭉날쭉하면 격자의 훑기 이점이 사라진다.

<br>

**3. 항목 안의 새 탭 링크**

목록 항목 오른쪽 끝에 그 서비스를 새 탭으로 여는 링크를 둔다. 왼쪽 목록과 오른쪽 내 바로가기에 같은 형태로 붙는다.

| 규칙 | 이유 |
| --- | --- |
| 링크는 평소에도 자리를 차지한다 | 커서를 올렸을 때만 나타나면 이름이 쓸 수 있는 폭이 바뀌어 말줄임 위치가 흔들린다 |
| 반투명으로 흐리게 만들지 않는다 | 투명도를 낮추면 배경과 합성된 뒤 대비가 컨트롤 기준 3:1을 넘지 못한다. 덜 두드러지게 하려면 투명도가 아니라 색을 낮춘다 |

| 상태 | 색 | 대비 |
| --- | --- | --- |
| 평소 | 보조 텍스트 색 | 라이트 5.74:1, 다크 7.06:1 |
| 커서를 올렸을 때, 키보드 포커스가 왔을 때 | 주색 | |

<br>

**4. 카테고리 묶음**

| 규칙 | 이유 |
| --- | --- |
| 묶음과 필터 버튼은 카테고리 목록 하나에서 만든다 | 화면에 카테고리를 따로 적어 두면 데이터와 화면이 갈라진다 |
| 묶음 순서는 카테고리 목록의 순서다. 카테고리마다 묶음 하나, 필터 버튼 하나다 | |
| 카테고리 안에 소제목을 두지 않는다 | 소제목과 카테고리가 겹치면 한 목록에 분류가 두 계층으로 보인다 |
| 필터 버튼은 검색창 아래 줄에 두고 넘치면 줄을 바꾼다. 접거나 드롭다운으로 감추지 않는다 | 한눈에 보이는 것이 이 방식의 이점이다 |

<br>

## 4-1-4 팝업 카드 이름

팝업 카드의 이름 칸은 두 줄까지 보이고 넘치면 말줄임된다.

<br>

**1. 한 줄에 들어가는 글자 수**

팝업 폭 320px에서 다음을 차례로 뺀다.

| 빼는 것 | 값 | 남는 폭 |
| --- | --- | --- |
| 팝업 바깥 좌우 여백 (20 × 2) | 40 | 280 |
| 카드 격자 좌우 안쪽 여백 (4 × 2) | 8 | 272 |
| 세로 스크롤바 | 6 | 266 |
| 3열 사이 간격 (12 × 2) | 24 | 242 |
| **3열로 나눈 카드 한 칸** | ÷ 3 | **80.67** |
| 카드 좌우 테두리 (1 × 2) | 2 | 78.67 |
| 카드 좌우 안쪽 여백 (4 × 2) | 8 | **70.67** |

한 줄 가용 폭은 70.67px이다. 스크롤바가 없으면 6px이 3열로 나뉘어 칸마다 2px씩 넓어져 72.67px이 된다. 글자 크기 12px에 자간을 0.5px 좁혀 한글 한 자가 11.5px이므로 한 줄에 한글 6자(69px)가 들어간다.

| 규칙 | 이유 |
| --- | --- |
| 카드 이름 글자 크기는 최대 12px이다 | 12.5px이면 여섯 자가 72px이 되어 한 줄에 들어가지 않고 줄바꿈 표를 전부 다시 정해야 한다. 폭이 정하는 값이므로 글자 크기 스케일에서도 따로 고정한다 |
| 카드 테두리를 폭 계산에 넣는다 | 테두리는 카드 폭 안쪽에 그려져 좌우 1px씩이 글자 폭에서 빠진다. 빠뜨리면 폭을 2px 넓게 잡아 표에 넣은 이름이 말줄임된다 |
| 카드 이름 칸에는 좌우 여백을 따로 두지 않는다 | 카드가 이미 좌우 4px을 넣는다. 스케일의 다음 단계인 4px을 더하면 폭이 62.67px로 줄어 여섯 자가 들어가지 않는다 |

카드 폭이나 글자 크기를 바꾸면 아래 줄바꿈 규칙과 데이터 검증기가 쓰는 한 줄 폭을 함께 고친다.

<br>

**2. 줄바꿈 표**

| 규칙 | 이유 |
| --- | --- |
| 공백이 있는 이름은 표에 넣지 않는다 | 어절 단위로 꺾인다 |
| 공백이 없는 긴 이름은 표에 첫 줄을 어디까지로 할지 적고, 그 지점에 보이지 않는 줄바꿈 기회 문자를 넣는다 | 꺾을 자리가 없으면 글자 사이 아무 데서나 꺾인다(`글로벌교육지 / 원팀`) |
| 표는 서비스 데이터가 아니라 화면 쪽에 둔다 | 줄바꿈 지점은 카드 폭에 딸린 표현 문제다. 데이터에 넣으면 다섯 필드 계약을 건드린다 |
| 아무 데서나 꺾는 동작은 남겨 둔다 | 빼면 표에 없는 이름이 한 줄로 말줄임돼 뒷부분이 사라진다 |
| 두 줄(6자 × 2)에도 들어가지 않는 이름은 꺾지 않고 예외 목록에 적는다 | 의미 단위로 꺾으면 둘째 줄이 말줄임돼 오히려 글자가 사라진다. 예외 목록은 빠뜨린 것이 아님을 남긴다 |
| 공백 없는 이름이 한 줄 폭을 넘는데 표에도 예외 목록에도 없으면 데이터 검증이 실패한다 | 서비스를 추가할 때 자동으로 걸려 표가 낡지 않는다 |
| 표에 있는 이름은 갈라진 두 줄이 각각 한 줄 폭에 들어가야 한다. 데이터 검증이 이것도 본다 | 한 줄을 넘는지만 보면 표에 넣은 항목이 조용히 말줄임되는 것을 놓친다 |

줄바꿈 지점은 첫 줄이 6자 안에 드는지와 두 줄의 길이 균형으로 정한다. "학과, 센터, 팀 앞에서 꺾는다" 같은 접미사 규칙으로 대신하지 않는다. `국제통상금융투자학부`를 접미사 규칙으로 꺾으면 `국제통상금융투자 / 학부`가 되어 첫 줄 8자가 들어가지 않는다. 맞는 지점은 `국제통상 / 금융투자학부`다.

공백을 넣어 고칠 수 있는 이름은 표에 넣기보다 데이터를 고친다. `환경학및환경공학과`는 `환경학 및 환경공학과`로 고쳐 어절 단위로 꺾이게 한다.
