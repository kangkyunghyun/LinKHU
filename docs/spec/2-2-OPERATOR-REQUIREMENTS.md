# 2-2 운영자 요구사항

이 문서는 운영 주체와 메인테이너가 이 제품에 요구하는 것을 정한다. 운영 요건은 안전한 데이터 갱신과 사람의 기억을 대신하는 검증, 메인테이너에게 전달되는 문의다.

방어 코드를 판단하는 테스트 규칙은 테스트 케이스에, 데이터 변경 절차와 손으로 적은 서비스 수는 데이터에, 문의 폼의 조건은 계약에, 릴리스와 스토어 제출 절차는 릴리스와 스토어 제출에 있다. ([7-2-1 자동 테스트](7-2-TEST-CASES.md#7-2-1-자동-테스트), [6-2-5 변경 절차](6-2-DATA.md#6-2-5-변경-절차), [6-2-7 손으로 적은 서비스 수](6-2-DATA.md#6-2-7-손으로-적은-서비스-수), [5-4 Google Forms](5-CONTRACT.md#5-4-google-forms), [7-5 릴리스](7-5-RELEASE.md), [7-6 스토어 제출](7-6-STORE.md))

<br>

### 2-2-1 운영 주체

| 주체 | 맡는 일 |
| --- | --- |
| 메인테이너 | 운영 요구사항을 정하고 결과를 확인함<br>교내 서비스가 바뀌면 데이터를 고쳐 내보냄<br>릴리스, 스토어 제출, 문의 대응, 외부 기여 검토 |
| 기여자 | 이슈와 PR로 데이터 수정과 기능을 제안함. 병합 여부는 메인테이너가 정함 |

<br>

### 2-2-2 핵심 기준 요약

| 구분 | 지키는 것 | 확인 | 기준 |
| --- | --- | --- | --- |
| 데이터 | 데이터 무결성 | 데이터 검증 | 오류 0건 |
| 데이터 | 랜딩 산출물과 지원 서비스 목록 문서의 최신 상태 | 랜딩 산출물 검사 | 통과. 어긋나면 생성 방법을 안내하며 실패 |
| 데이터 | 아이콘 라이트와 다크 짝 | 다크 아이콘 짝 검증 | 모든 짝이 있고 다크 벌이 최신이며 배경이 투명 |
| 코드 | 기존 동작의 회귀 여부 | 자동 테스트 | 전부 통과 |
| 코드 | 두 벌 구현의 일치 | 자동 테스트 | 검색 순위, 문의 폼 필드, 테마 규칙, 다크 아이콘 경로가 확장과 랜딩에서 같음<br>릴리스 노트의 `### Internal` 제거 규칙이 랜딩과 Firefox 제출에서 같음 |
| 배포 | 패키지 재현성 | 자동 테스트 | 같은 소스에서 바이트 단위로 같은 ZIP |
| 배포 | 릴리스 무결성 | 릴리스 워크플로, 스토어 제출 워크플로 | 태그와 매니페스트 버전 일치, 릴리스 노트 존재. 검사에 실패하면 릴리스 생성과 스토어 제출이 모두 중단됨 |
| 전체 | 위 확인 전부 | 빌드 | CI가 PR마다 같은 빌드를 실행 |
| 사람 | 화면 동작, 스토어 심사, 교내 사이트의 실제 작동 | 수동 검증 | 수동 검증 항목 통과 |

<br>

### 2-2-3 서비스 데이터 갱신

교내 웹서비스는 메인테이너가 통제할 수 없는 곳에서 바뀐다. 데이터 갱신이 가장 잦은 운영 작업이다.

| 규칙 | 이유 |
| --- | --- |
| 지원 서비스 목록의 원본은 하나 | 확장 화면과 랜딩 산출물이 모두 지원 서비스 목록에서 나옴 |
| 지원 서비스 목록 문서는 데이터에서 생성함. 손으로 고치지 않음 | 손으로 옮긴 사본이 한 번 어긋났음 |
| 데이터 검증 결과를 PR 본문에 남김 | 검증 내용을 다시 확인할 수 있어야 함 |
| 한 PR에서 아이콘을 한꺼번에 많이 바꾸지 않음 | 되돌릴 단위를 작게 유지함 |

| 데이터를 바꾸면 함께 바뀌는 것 | 빠뜨렸을 때 |
| --- | --- |
| 랜딩 산출물과 지원 서비스 목록 문서 | CI가 막음 |
| 문서와 화면에 적힌 서비스 수 | 틀린 숫자가 그대로 남음 |

<br>

### 2-2-4 문의 대응

| 요구 | 이유 |
| --- | --- |
| 팝업, 설정, 랜딩에서 GitHub 계정 없이 문의를 보낼 수 있음 | 사용자 대부분에게 GitHub 계정이 없음 |
| 세 화면이 같은 폼과 같은 본문, 이메일, 유형 필드를 씀 | 경로가 갈라지면 수집 결과가 나뉨 |
| 문의 유형을 별도 질문으로 수집함 | 응답 시트에서 유형으로 거를 수 있음 |
| 확장에서 문의 폼이 설정되지 않았으면 보내기를 누를 때 준비 중 안내 문구를 보임 | 폼 없이 보낸 문의가 사라지지 않음 |
