# 1. 배경

이 문서는 LinKHU가 무엇이고 어떤 문제를 푸는지, 제품이 하지 않는 일, 기술 기반과 저장소 구조, 문서 전체가 쓰는 용어를 정한다.

<br>

## 1-1 제품 정의

LinKHU는 경희대학교 구성원이 자주 쓰는 교내 웹서비스로 한 번에 이동하게 돕는 **브라우저 확장 프로그램**이다.

브라우저 툴바 아이콘을 누르면 팝업이 열린다. 팝업에는 사용자가 골라 둔 바로가기가 격자로 보인다. 어떤 서비스를 담고 어떤 순서로 둘지는 설정 페이지에서 정한다.

GitHub Pages에는 확장 프로그램을 소개하고 설치로 안내하는 랜딩이 있다.

<br>

## 1-2 문제와 가치

경희대학교의 학사, 학습, 생활 서비스는 여러 도메인에 흩어져 있다. 인포21, e-Campus, 수강신청, 단과대와 학과 홈페이지의 주소가 모두 다르다. 학과 홈페이지는 학생이 직접 검색해야 찾을 때가 많다.

브라우저 북마크로 모아도 문제가 남는다. 쓰는 사이트가 늘수록 북마크가 끝없이 쌓인다. 교내 사이트는 같은 학교 아이콘을 쓰는 경우가 많아 목록에서 서로 구분하기 어렵다. 사이트 주소가 바뀌면 사용자가 다시 검색해 찾고 북마크를 새로 등록해야 한다.

| 가치 | 내용 |
| --- | --- |
| 탐색 비용 제거 | 매번 검색하지 않고 학과 홈페이지까지 포함한 목록에서 골라 담아 쓴다 |
| 한눈에 구분 | 서비스마다 따로 그린 아이콘을 써서 비슷한 사이트끼리 헷갈리지 않는다 |
| 주소 관리 | 주소가 바뀌면 메인테이너가 데이터를 고쳐 업데이트로 내보낸다. 사용자가 담아 둔 목록은 그대로이고 바뀐 주소로 열린다 |
| 개인화 | 전공과 학년에 따라 필요한 서비스가 다르다. 평소 팝업에는 사용자가 고른 것만 보이고, 검색할 때만 전체 서비스에서 찾는다 |

메인테이너의 갱신이 늦어도 사용자가 잃는 것은 없다. 그동안은 북마크를 쓸 때처럼 직접 검색해 찾으면 되기 때문이다.

<br>

## 1-3 하지 않는 것

표의 항목은 권한이 늘거나 서버가 생기는 일이라 기능 판단이 아니라 제품 판단으로 다룬다. 시작하기 전에 결정 기록을 남긴다.

| 하지 않는 것 | 의미 | 이유 |
| --- | --- | --- |
| 로그인과 인증 대행 | 사용자를 대신해 로그인하지 않는다 | 각 서비스의 인증은 해당 사이트에서 이뤄진다 |
| 교내 데이터 크롤링과 중계 | 공지, 성적, 식단 같은 콘텐츠를 가져오지 않는다 | 이동만 시킨다 |
| 확장 사용 행동 수집 | 확장에 분석 SDK, 텔레메트리, 원격 로그가 없다 | 최소 권한 |
| 계정 기반 동기화 | 설정은 브라우저 로컬 저장소에만 남는다 | 서버가 없다 |
| 경희대학교 공식 서비스 지위 | 공식 산출물이 아니다 | 공식 색상을 쓰되 대학을 사칭하지 않는다 |

랜딩은 확장과 별개로 방문과 설치에 관한 동작만 Google Analytics로 센다. 스토어 링크 클릭, 휴대폰 설치 안내의 주소 복사와 QR 코드 펼침이 해당한다.

<br>

## 1-4 기술 스택

**1. 런타임**

빌드 단계가 없다. 번들러, 트랜스파일러, 프레임워크를 쓰지 않고 `src/`의 정적 HTML, CSS, JavaScript가 그대로 확장 프로그램이 된다. 런타임 의존성과 개발 의존성이 모두 없다.

Node.js는 개발 도구로만 쓴다. 검증, 생성, 패키징, 스토어 제출 스크립트와 테스트가 Node.js에서 실행된다.

<br>

**2. 매니페스트와 권한**

Manifest V3를 쓴다. 요청하는 권한은 아래 둘이 전부다.

| 항목 | 값 | 용도 |
| --- | --- | --- |
| `permissions` | `storage` | 바로가기 순서, 테마, 단축키 안내를 닫았는지, 버전 캐시 저장 |
| `host_permissions` | `https://api.github.com/repos/kangkyunghyun/LinKHU/releases/latest` | 최신 릴리스 버전 조회 |

`tabs` 권한은 요청하지 않는다. 탭을 여는 `chrome.tabs.create`와 `chrome.tabs.update`는 별도 권한 없이 동작한다.

팝업을 여는 단축키는 매니페스트에 `Ctrl+Shift+L`(macOS `Command+Shift+L`)을 제안값으로 등록한다.

<br>

**3. 대상 브라우저**

| 브라우저 | 비고 |
| --- | --- |
| Chrome | Chrome Web Store 배포 |
| Firefox | `browser_specific_settings.gecko`에 `strict_min_version` 140.0 지정<br>`data_collection_permissions.required`를 `["none"]`으로 선언 |
| Whale | Chromium 기반. Chrome용 패키지를 그대로 씀 |

<br>

## 1-5 저장소 구조

```text
src/            확장 프로그램 소스. 숨김 파일을 뺀 폴더 전체가 패키징 대상
  manifest.json       MV3 매니페스트
  popup.html/css/js   팝업 화면
  options.html/css/js 설정 화면
  theme.css           디자인 토큰
  theme.js            테마 모드 해석, 저장, 적용
  data.js             지원 서비스 목록 원본
  shared.js           팝업과 설정이 함께 쓰는 검색, 정렬, 표시 규칙
  version.js          현재 버전 표시와 업데이트 안내
  feedback.js         문의 폼 전송
  icons/              확장 아이콘 (16, 48, 128)
  images/             서비스 아이콘 (common, colleges, departments, dark)

landing/        GitHub Pages로 배포하는 랜딩
  index.html, landing.css, landing.js   랜딩 페이지
  theme.js                              랜딩 테마 모드 해석, 저장, 적용
  assets/services.json                  data.js에서 생성한 랜딩 검색 데이터
  assets/images/                        src/images/에서 복사한 서비스 아이콘

assets/icons/   서비스 아이콘 SVG 원본
docs/           프로젝트 문서
  README.md               문서 폴더 안내
  supported-services.md   지원 서비스 목록 사본
  spec/                   이 스펙과 결정 기록
  copy/                   스토어와 커뮤니티 문구
  releases/               버전별 릴리스 노트

scripts/        검증, 생성, 패키징, 스토어 제출 스크립트 (Node.js)
tests/          node --test 대상 테스트
.github/        워크플로, 이슈 템플릿, PR 템플릿
.claude/skills/ 서비스 아이콘과 릴리스 문구 작업 가이드
```

`dist/`는 패키징 산출물이며 버전 관리 대상이 아니다.

<br>

## 1-6 공통 용어

| 용어 | 의미 |
| --- | --- |
| **서비스** | LinKHU가 바로가기를 제공하는 교내 웹사이트 하나. 지원 서비스 목록의 항목 하나 |
| **식별자** | 서비스마다 붙인 영문 소문자 `id`. 순서 저장과 검색에 씀 |
| **카테고리** | 서비스를 묶는 분류 |
| **내 바로가기** | 사용자가 팝업에 보이려고 직접 고르고 정렬한 서비스들 |
| **기본 목록** | 바로가기 순서를 한 번도 저장하지 않았을 때 팝업이 보이는 서비스들. 카테고리와 별개 |
| **팝업** | 툴바 아이콘을 눌렀을 때 열리는 `popup.html` 화면 |
| **설정 페이지** | 탭으로 열리는 `options.html` 화면 |
| **랜딩** | GitHub Pages로 배포하는 `landing/index.html` 소개 페이지. 화면의 링크 이름은 "홈페이지" |
| **메인테이너** | 저장소를 관리하고 데이터 갱신, 릴리스, 스토어 제출, 문의 대응을 맡는 사람 |
| **디자인 토큰** | 화면의 색, 여백, 반경, 그림자, 글자 크기를 정하는 CSS 변수 |
| **서비스 아이콘** | 서비스 하나를 그린 그림 파일 |
| **UI 아이콘** | 설정, 검색, 테마 전환 같은 화면 기능의 기호 |
