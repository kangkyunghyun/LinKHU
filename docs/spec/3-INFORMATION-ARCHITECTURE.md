# 3. 정보 구조

이 문서는 제품이 다루는 단위와 카테고리, 화면별 노출 범위, 기본 목록, 검색 대상과 순위를 정한다.

화면 배치는 레이아웃에, 확장과 랜딩의 디자인 성격은 UI 시스템에, 데이터 필드 형식과 중복 규칙은 데이터에 있다. ([4-1 레이아웃](4-1-LAYOUT.md), [4-2-3 확장 우선 원칙](4-2-UI-SYSTEM.md#4-2-3-확장-우선-원칙), [6-2 데이터](6-2-DATA.md))

<br>

## 3-1 다루는 단위

LinKHU가 다루는 단위는 **서비스 하나**다. 사용자에게는 누르면 열리는 바로가기 하나다.

| 속성 | 쓰이는 곳 |
| --- | --- |
| 이름 | 카드와 목록에 적힘 |
| 아이콘 | 카드와 목록에 보임 |
| 주소 | 눌렀을 때 가는 곳 |
| 카테고리 | 설정 페이지의 묶음과 필터, 랜딩 검색 결과의 보조 줄 |
| 식별자 | 순서 저장과 검색에 씀. 확장 화면에는 보이지 않고 랜딩 검색 결과의 보조 줄에 보임 |

서비스 하나는 학생이 따로 찾아가는 목적지 하나다. 다른 사이트 안의 게시판이나 페이지라도 학생이 하나의 서비스로 찾아가면 항목으로 만든다. 공지사항, 캠퍼스별 식단이 그런 예다. 같은 사이트의 일반 메뉴를 하나씩 항목으로 나누지는 않는다.

같은 주소나 같은 이름으로 가는 항목은 두 번 등록하지 않는다. 같은 곳으로 가는 항목이 여러 개면 선택지가 아니라 방해가 되고, 같은 이름은 카드만으로 구별할 수 없다. 학과 항목은 학과 홈페이지나 전공 소개 페이지가 따로 있을 때 만든다.

<br>

## 3-2 카테고리

카테고리는 여덟 개다. 표의 순서가 화면 표시 순서다. 서비스 수는 지원 서비스 목록 전체를 센 값이다. 문서에서 서비스 수를 적는 곳은 이 표 하나다.

| 카테고리 | 서비스 수 |
| --- | --- |
| 학사·포털 | 13 |
| 생활·복지 | 12 |
| 장학·진로·창업 | 5 |
| 교육·역량 | 16 |
| 캠퍼스·문화 | 11 |
| 대학·행정 | 15 |
| 단과대 | 26 |
| 학과 | 69 |
| **합계** | **167** |

| 규칙 | 이유 |
| --- | --- |
| 분류는 한 계층이다. 카테고리 안에 하위 분류를 두지 않는다 | 구분이 더 필요하면 카테고리를 늘린다 |
| 서비스 하나는 카테고리 하나에만 속한다 | 어느 묶음에서 찾을지가 사람마다 갈리면 훑기의 이점이 사라진다 |
| 카테고리 값을 늘리거나 바꾸는 것은 계약 변경이다 | 데이터 필드 규칙과 검증기를 함께 고친다 |

<br>

## 3-3 화면별 범위

| 화면 | 기본으로 보여주는 것 | 전체 목록 | 분류 노출 |
| --- | --- | --- | --- |
| 팝업 | 내 바로가기 | 검색할 때만 | 없음 |
| 설정 | 전체 서비스 | 항상 | 카테고리 묶음과 필터 |
| 랜딩 | 랜딩 기본 서비스 3개 | 검색할 때만, 최대 5개 | 결과마다 보조 줄에 카테고리와 식별자. 묶음과 필터 없음 |

| 규칙 | 이유 |
| --- | --- |
| 팝업은 고른 것만 보여준다 | 고르는 일은 설정 페이지가 맡는다 |
| 팝업 검색은 전체 서비스를 대상으로 한다 | 담아 두지 않은 서비스도 찾아서 열 수 있어야 한다 |
| 카테고리 묶음과 필터는 설정 페이지에만 둔다 | 열 개 남짓한 팝업 카드에 분류 머리글을 씌우면 밀도만 떨어진다 |

랜딩의 기본 서비스는 `info21`, `ecampus`, `sugang`이다. 랜딩의 기본 서비스와 결과 상한은 랜딩 전용 표시 규칙이며 확장과 관계없다.

<br>

## 3-4 기본 목록

기본 목록은 아래 열 개다.

```text
info21  ecampus  everytime  notice  library
scholarship  intern  sugang  chatkhu  ois
```

| 규칙 | 이유 |
| --- | --- |
| 표시 순서는 이름 가나다순이다. 위 나열 순서가 아니다 | 설정 페이지 왼쪽 목록과 같은 기준이라 두 화면의 순서 감각이 맞는다 |
| 지원 서비스 목록에 없는 id는 표시하지 않는다 | 서비스를 지워도 깨진 항목이 생기지 않는다 |
| 바로가기 순서를 한 번도 저장하지 않은 사용자에게만 쓴다. 모두 빼고 저장하면 빈 목록이 저장되고 기본 목록으로 돌아가지 않는다 | 이미 고른 사용자의 화면은 기본 목록이 바뀌어도 그대로다 |
| 서비스를 추가해도 기본 목록에 저절로 들어가지 않는다 | 기본 목록을 바꾸는 것은 신규 사용자의 첫 화면을 바꾸는 일이다 |

<br>

## 3-5 검색이 다루는 범위

검색 대상은 이름, 식별자, 카테고리 세 가지다. 주소는 검색 대상이 아니다. 검색어와 대상을 모두 `ko-KR` 기준 소문자로 바꾸고 공백을 모두 지운 뒤 비교하므로 "e campus"와 "ecampus"가 같다.

팝업과 랜딩은 아래 점수로 결과를 정렬한다.

| 점수 | 조건 |
| --- | --- |
| 0 | 이름이 검색어로 시작 |
| 1 | 이름에 검색어 포함 |
| 2 | 식별자가 검색어로 시작 |
| 3 | 식별자에 검색어 포함 |
| 4 | 카테고리에 검색어 포함 |

점수가 낮을수록 위에 온다. 어느 조건에도 맞지 않으면 결과에서 뺀다. 동점이면 지원 서비스 목록의 순서를 유지한다. 정렬이 안정적이지 않으면 같은 검색어에도 결과 순서가 달라진다.

검색 순위는 팝업과 랜딩이 같아야 한다. 팝업에서 `Enter`가 첫 결과를 열기 때문에 순위가 갈리면 같은 검색어에 다른 서비스가 열린다.

설정 페이지는 순위를 매기지 않는다. 이름, 식별자, 카테고리를 이어 붙인 문자열에 검색어가 들어 있으면 보이고, 카테고리 필터와 함께 걸린다. 카테고리 묶음 안의 이름순은 그대로 둔다.
