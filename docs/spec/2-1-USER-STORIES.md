# 2-1 사용자 스토리

이 문서는 학생 사용자가 누구이며 LinKHU를 어떻게 쓰는지, 각 쓰임에서 무엇을 기대하는지 정한다.

검색 대상과 순위는 정보 구조에, 테마 모드와 저장 규칙은 테마에, 키와 클릭의 처리, 단축키 안내, 필터, 랜딩 동작은 인터랙션에, 실패 시 동작과 문구는 오류 처리에 있다. ([3-5 검색이 다루는 범위](3-INFORMATION-ARCHITECTURE.md#3-5-검색이-다루는-범위), [4-3 테마](4-3-THEME.md), [6-1 인터랙션](6-1-INTERACTION.md), [7-1 오류 처리](7-1-ERROR-HANDLING.md))

<br>

### 2-1-1 사용자

사용자는 PC 브라우저에 LinKHU를 설치해 교내 웹서비스로 이동하는 경희대학교 학생이다. 학점교류로 경희사이버대 강의를 듣는 학생도 같은 기대를 갖는다.

사용자는 설정 페이지에서 쓰는 서비스를 골라 순서를 정하고, 평소에는 팝업을 열어 바로가기를 누르거나 검색해 이동한다. 설치하기 전이나 업데이트된 뒤에는 랜딩에서 지원 서비스와 변경 내용을 본다.

<br>

### 2-1-2 기대

**1. 팝업 열기**

브라우저 어디에 있든 툴바 아이콘이나 키보드 단축키로 팝업을 연다.

| 기대 |
| --- |
| 팝업을 열면 내가 정한 순서대로 바로가기가 보임 |
| 아직 순서를 저장한 적이 없어도 기본 목록이 보여 바로 쓸 수 있음 |
| 다른 프로그램이 같은 단축키를 써서 등록되지 않았으면, 직접 지정할 위치를 알려 줌 |
| 단축키 안내를 닫으면 다시 보이지 않음 |

<br>

**2. 바로가기 이동**

목록에서 서비스를 눌러 이동한다. 학기 초처럼 여러 서비스를 한꺼번에 열 때도 있다.

| 기대 |
| --- |
| 카드를 누르면 새 탭에서 그 서비스가 바로 보이고 팝업이 닫힘 |
| `Ctrl`/`Cmd` + 클릭이나 휠 클릭으로 여러 서비스를 뒤에 열 수 있고, 그동안 팝업이 닫히지 않음 |
| 같은 서비스가 두 번 보이지 않음 |
| 아이콘을 불러오지 못해도 깨진 그림이 보이지 않음 |

<br>

**3. 검색**

목록을 눈으로 훑지 않고 이름을 입력해 찾는다.

| 기대 |
| --- |
| 담아 두지 않은 서비스도 찾아서 열 수 있음 |
| 띄어쓰기를 달리 써도 찾힘 |
| 키보드만으로 검색창에 들어가고, `Enter`로 첫 결과를 지금 탭에서 열 수 있음 |
| 한글을 조합하는 중에 누른 `Enter`가 엉뚱한 서비스를 열지 않음 |
| 검색어를 빠르게 바꿔도 앞 검색어의 결과가 뒤늦게 화면을 덮지 않음 |
| 팝업과 랜딩에서 같은 검색어를 넣으면 결과 순서가 같음 |
| 일치하는 결과가 없으면 없다고 알려 줌 |

<br>

**4. 숫자 단축키**

자주 쓰는 앞쪽 바로가기를 키보드만으로 연다.

| 기대 |
| --- |
| `1`~`9` 키로 화면에 보이는 n번째 카드를 누른 것과 같이 열림 |
| 검색창이나 문의 본문에 숫자를 칠 때는 카드가 열리지 않음 |

<br>

**5. 내 바로가기 구성**

내 전공과 학년에 맞는 서비스만 팝업에 두고 원하는 순서로 정렬한다.

| 기대 |
| --- |
| 담을 수 있는 서비스가 카테고리별, 이름순으로 보임 |
| 드래그로 담고, 빼고, 순서를 바꿀 수 있고, 그 순서가 팝업에 그대로 보임 |
| 이미 담은 서비스는 왼쪽 목록에서 사라져 양쪽에 동시에 보이지 않음 |
| 긴 학과 목록에서도 끌어서 위아래로 옮길 수 있음 |
| 담기 전에 항목의 링크로 그 서비스를 새 탭에서 확인할 수 있고, 링크를 끌어도 항목이 딸려 가지 않음 |
| 이름을 모르면 카테고리 필터로 해당 분류만 볼 수 있음 |
| 검색어와 필터는 왼쪽 목록에만 걸리고 내 바로가기에는 영향이 없음 |
| 드래그만으로는 저장되지 않고 저장 버튼을 눌러야 저장됨 |
| 검색어나 필터를 건 채 저장해도 저장되는 순서가 같음 |
| 저장에 성공했는지 실패했는지 알림 창으로 알려 줌 |
| 새로고침하거나 팝업을 다시 열어도 저장한 순서가 그대로임 |

<br>

**6. 버전 확인과 문의**

쓰는 버전이 최신인지 확인하고, 불편한 점을 개발자에게 알린다.

| 기대 |
| --- |
| 팝업에서 현재 버전을 볼 수 있음 |
| 최신 릴리스보다 낮을 때만 업데이트 안내가 보이고, 누르면 내가 쓰는 브라우저의 스토어로 감 |
| 최신 버전을 확인하지 못해도 바로가기는 그대로 열림 |
| 팝업, 설정, 랜딩에서 GitHub 계정 없이 문의 유형을 골라 의견을 보낼 수 있음 |
| 답변받을 이메일은 쓰지 않아도 됨 |
| 유형이나 내용이 빠졌거나 이메일 형식이 틀리면 보내기 전에 알려 줌 |
| 보내는 중에는 다시 보낼 수 없고, 끝나면 전송 결과를 알려 줌 |

<br>

**7. 랜딩에서 변경 이력 보기**

설치하기 전이나 업데이트된 뒤에 무엇이 바뀌었는지 랜딩에서 본다.

| 기대 |
| --- |
| 최근 릴리스의 변경 내용을 볼 수 있고, 새 버전을 내면 랜딩이 저절로 따라옴 |
| 내부 정리 기록은 보이지 않음 |
| 가장 최근 것만 펼쳐져 있어 소개 흐름을 끊지 않음 |
| 더 오래된 이력은 GitHub 릴리스로 이어짐 |
| 이력을 불러오지 못해도 빈 상자가 남지 않고 랜딩의 나머지는 그대로 동작함 |
| 이력 본문의 기호가 글자 그대로 보임 |

<br>

**8. 테마 고르기**

화면을 밝게 볼지 어둡게 볼지 정한다. 운영체제는 밝게 쓰지만 이 화면만 어둡게 보고 싶을 때가 있다.

| 기대 |
| --- |
| 팝업, 설정, 랜딩의 머리에 있는 버튼 하나로 시스템 설정, 라이트, 다크를 오감 |
| 버튼 아이콘이 지금 모드를 보여 주고, 스크린 리더는 지금 모드와 다음 모드를 함께 읽음 |
| 배경, 글자, 테두리와 서비스 아이콘이 함께 바뀜 |
| 라이트나 다크로 고정하면 운영체제 설정을 바꿔도 따라가지 않음 |
| 시스템 설정으로 두면 운영체제를 바꾸는 즉시 열려 있는 화면이 따라옴 |
| 다시 열어도 고른 대로 열림 |
| 시스템 설정으로 두고 다시 열거나 랜딩을 다시 열 때 밝은 화면이 스쳤다 어두워지는 깜빡임이 없음 |
| 확장에서 라이트나 다크를 고르고 다시 열면 화면이 바뀌더라도 한 번으로 끝남 |
| 확장과 랜딩에서 고른 테마는 서로 영향을 주지 않음 |

<br>

**9. 휴대폰에서 랜딩 열기**

휴대폰으로 랜딩을 봤을 때 PC에서 설치할 방법을 안다.

| 기대 |
| --- |
| 휴대폰이나 태블릿에서는 확장을 PC 브라우저에서 설치한다는 안내와 랜딩 주소가 보임 |
| 주소를 복사하거나 QR 코드로 PC에 옮길 수 있음 |
| 복사하지 못하면 직접 복사하는 방법을 알려 줌 |
| PC 브라우저에서는 안내가 보이지 않음 |
