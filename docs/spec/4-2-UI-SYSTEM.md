# 4-2 UI 시스템

이 문서는 경희대 공식 색상의 사용 규칙, 디자인 토큰의 값과 쓰는 자리, 확장과 랜딩이 맞추는 값, 확장과 랜딩 중 무엇이 디자인 기준인지, UI 아이콘 규칙을 정한다.

테마별 색 토큰 값과 대비 기준은 테마에, 화면별 치수는 레이아웃에, 서비스 아이콘 규칙은 서비스 아이콘에 있다. ([4-3-4 구현 방식과 토큰 계약](4-3-THEME.md#4-3-4-구현-방식과-토큰-계약), [4-3-5 대비 기준](4-3-THEME.md#4-3-5-대비-기준), [4-1 레이아웃](4-1-LAYOUT.md), [4-6 서비스 아이콘](4-6-SERVICE-ICON.md))

<br>

### 4-2-2 디자인 토큰 규칙

**1. 공통**

| 규칙 | 내용 |
| --- | --- |
| 원본 | 확장 화면의 색, 여백, 반경, 그림자, 글자 크기는 확장 전용 토큰 한 벌이 정함. 팝업과 설정은 화면 스타일보다 토큰을 먼저 불러옴 |
| 색 | 모든 색은 토큰을 거침. 확장 스타일과 마크업에 색 값을 직접 쓰지 않음 |
| 테마에 따라 갈리는 기능색 | 브랜드와 무관한 색이라도 라이트와 다크에서 한 값으로 대비를 만족할 수 없으면 토큰으로 둠 |
| SVG 선과 채움 | 표현 속성은 토큰을 받지 못하므로 인라인 스타일로 줌. 현재 색을 상속하는 아이콘은 해당 없음 |
| 토큰을 해석하지 않는 자리 | 랜딩의 브라우저 테마 색 메타 정보 같은 자리는 `#a40f16`을 직접 씀 |
| 같은 기능 | 팝업과 설정에 같은 기능을 그린 요소(문의 패널, 테마 상태 문구)는 같은 토큰을 씀 |

<br>

**2. 간격**

확장의 모든 여백은 아래 값 중 하나다. 예외는 스크린 리더 전용으로 숨기는 요소의 `-1px`와 팝업 헤더 버튼 묶음을 제목과 맞추는 위 `-4px`뿐이다. 반경, 글자 크기, 높이, 너비, 포커스 표시 간격에는 쓰지 않는다.

| 값 |
| --- |
| `4px` |
| `8px` |
| `12px` |
| `16px` |
| `20px` |
| `24px` |
| `32px` |

| 자리 | 값 | 이유 |
| --- | --- | --- |
| 설정 목록 스크롤 영역의 오른쪽 거터 | `8px` | 스크롤바 `6px`를 피함 |
| 목록 항목의 새 탭 링크 안쪽 | `4px` | 클릭 대상 24×24. WCAG 2.2 최소 타깃 크기 |
| 팝업 헤더 아이콘 버튼 안쪽 | `4px` | 28×28. 320px 헤더 한 줄에 들어감 |
| 설정 헤더 아이콘 버튼 안쪽 | `8px` | 36×36 |

<br>

**3. 반경과 그림자**

| 토큰 | 값 | 쓰이는 곳 |
| --- | --- | --- |
| 반경 작음 | `4px` | 포커스 표시, 스크롤바 손잡이 |
| 반경 기본 | `8px` | 입력, 버튼, 아이콘 버튼, 목록 항목, 새 탭 링크, 드롭 영역, 단축키 안내 박스, 설정 단 |
| 반경 큼 | `12px` | 팝업 카드, 떠 있는 문의 패널 |
| 알약 | `999px` | 카테고리 필터 칩, 문의 유형 칩 |
| 카드 그림자 | `0 4px 6px` 그림자색 | 팝업 카드 평상시 |
| 카드 hover 그림자 | `0 6px 12px` 주색 그림자 | 팝업 카드 hover |
| 포커스 링 | `0 0 0 3px` 주색 링 | 입력 요소 포커스 |
| 패널 그림자 | `0 8px 24px` 그림자색 | 떠 있는 문의 패널 |
| 드롭 대상 윤곽 | 안쪽 `1px` 주색 테두리 | 드래그 중 놓을 수 있는 영역 |

랜딩은 반경 `12px`, `20px`, `32px`과 그림자 두 단계를 따로 둔다.

<br>

**4. 글자 크기**

| 토큰 | 값 | 쓰이는 곳 |
| --- | --- | --- |
| 제목 | `20px` | 팝업 헤더의 제품 이름 |
| 머리글 | `16px` | 설정 화면의 단 제목, 저장 버튼 |
| 본문 | `13px` | 기본값. 입력, 버튼, 목록 이름, 안내 문단 |
| 보조 | `12px` | 버전 표시, 상태 알림, 푸터 링크 |
| 카드 이름 | `12px` | 팝업 카드 이름. 카드 폭이 정하는 고정값이라 본문 크기를 올려도 함께 올리지 않음 |

글자 크기는 용도로 고른다. 랜딩은 이 단계를 쓰지 않는다.

<br>

**5. 확장과 랜딩이 맞추는 값**

랜딩은 확장의 토큰을 불러올 수 없어 같은 값을 따로 갖는다. 맞추는 값을 바꾸면 같은 PR에서 양쪽을 바꾼다.

| 토큰 | 맞춤 |
| --- | --- |
| 주색(글자), 주색 채움, 주색 채움 hover, 주색 진함, 주색 옅음, 주색 위 글자 | 라이트와 다크 모두 같은 값 |
| 표면과 중성 계열 | 맞추지 않음 |
| 확장 전용(주색 테두리, 주색 링, 주색 그림자, 알림색) | 대상 아님 |
| 랜딩 전용(포커스, 주색 위 보조 글자, 사용 방법 강조색) | 대상 아님 |

<br>

### 4-2-3 확장 우선 원칙

확장 UI가 디자인 기준이고 랜딩은 확장에 맞춘다.

| 화면 | 성격 | 쓰는 표현 |
| --- | --- | --- |
| 확장 | 제품 그 자체. 320px에서 바로 목표를 달성하는 도구 | 밀도 우선, 장식 없음 |
| 랜딩 | 제품을 소개하는 홍보 페이지. 넓은 화면에서 스크롤하며 읽음 | 큰 여백, 그라디언트, 글로우, hover 전환 효과 |

| 규칙 | 내용 |
| --- | --- |
| 브랜드 색 변경 | 확장을 기준으로 정하고 랜딩이 따라옴 |
| 랜딩 표현 | 확장 UI로 가져오지 않음. 랜딩을 확장과 똑같이 만들지 않아도 됨 |
| 장식 | 조작을 느리게 만들면 뺌 |

### 4-2-4 UI 아이콘

| 종류 | 위치 |
| --- | --- |
| UI 아이콘 | 팝업, 설정, 랜딩의 인라인 SVG. 드래그 손잡이, 새 탭 링크 아이콘, 랜딩 검색 결과의 홑화살괄호는 스크립트가 넣음 |
| 서비스 아이콘 | 확장 패키지 안의 이미지. 랜딩은 그 사본을 검색 결과와 기능 소개 카드에 씀 |

| 규칙 | 내용 |
| --- | --- |
| 출처 | [Reicon](https://github.com/huntiezz/reicon). MIT, 24×24 그리드, Outline 굵기. 직접 그리거나 다른 세트를 섞지 않음 |
| 가져오는 방법 | 패키지를 추가하지 않고 필요한 SVG 마크업만 인라인으로 |
| 색 | 채움 아이콘은 현재 글자색을 상속함. 선 아이콘(돋보기, 홑화살괄호)은 토큰 색을 인라인 스타일로 줌 |
| 크기 | 그리드 `0 0 24 24`를 유지하고 표시 크기만 정함 |
| 접근성 | 장식 아이콘은 스크린 리더에서 숨김. 의미가 있는 아이콘은 인접 텍스트나 접근성 이름을 줌 |
| 이모지 | UI 기호로 쓰지 않음. 본문과 안내 문구 속 이모지는 대상 아님 |
| 브라우저 로고 | Chrome, Firefox, Whale 로고는 공식 원본을 그대로 씀 |

| 화면 기호 | 아이콘 |
| --- | --- |
| 테마 시스템 설정 | 모니터 |
| 테마 라이트 | 해 |
| 테마 다크 | 달 |
| 설정 | 톱니바퀴 |
| 검색 | 돋보기 |
| 드래그 손잡이 | 가로줄 넷 |
| 새 탭 열기 | 사각형 공유 |
